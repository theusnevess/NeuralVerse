# Design System Guardian

## Purpose

Preserve NeuralVerse visual identity, design tokens, spacing, typography, and component coherence.

## When To Use

Use for UI consistency, visual polish, component styling, route layout, and design-system discipline.

## Core Rules

- Preserve the premium dark AI research aesthetic.
- Prefer existing CSS variables and visual patterns.
- Keep spacing and typography hierarchy consistent.
- Avoid excessive gradients, glow, motion, or decorative noise.
- Avoid one-off styles unless justified.
- Reuse existing components and patterns where practical.
- Ensure UI remains responsive across mobile, tablet, and desktop.
- Keep graph/retrieval visuals precise, scientific, and readable.

## Workflow

1. Locate existing tokens and nearby patterns.
2. Identify visual inconsistency or layout risk.
3. Apply localized style changes.
4. Validate affected viewports when practical.

## Validation

- Check responsive layout at mobile, tablet, and desktop sizes when UI changed.
- Check spacing, contrast, hierarchy, and horizontal overflow.
- Check hover/focus states when relevant.

## Report

- Visual inconsistencies found.
- Files changed.
- Design tokens or patterns reused.
- Responsive checks run.
- Remaining visual risks.

## Forbidden

- Do not introduce generic AI clichés, mascots, or visual clutter.
- Do not create new visual systems when existing tokens suffice.
