# React UI Polish

## Purpose

Improve React/UI aesthetics, spacing, responsiveness, hierarchy, and interaction quality while preserving NeuralVerse visual identity.

## When To Use

Use for visual refinement, layout polish, route presentation, component interaction quality, and React UI cleanup.

## Core Rules

- Preserve the premium dark AI research platform aesthetic.
- Keep interfaces scientific, restrained, precise, and low-noise.
- Use subtle cyan/blue accents consistently.
- Improve spacing, alignment, hierarchy, and responsive behavior.
- Remove redundant text and awkward empty areas.
- Keep interactions clear and stable.
- Use CSS variables/design tokens when available.
- Avoid unnecessary dependencies.

## Workflow

1. Inspect nearby components and styles before editing.
2. Identify the smallest visual or interaction improvement.
3. Preserve existing component boundaries and design patterns.
4. Validate affected routes visually when practical.

## Validation

- Check affected routes visually.
- Test mobile, tablet, and desktop for layout changes.
- Check console when browser behavior is affected.

## Report

- UI issue addressed.
- Files changed.
- Routes or viewports checked.
- Remaining visual risks.

## Forbidden

- Do not add visual clutter, mascots, generic AI graphics, or excessive gradients.
- Do not invent new product requirements to fill space.
