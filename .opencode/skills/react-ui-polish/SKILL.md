# React UI Polish Skill

Use this skill for visual and interaction refinement.

Design direction:
- Premium dark AI research platform.
- Scientific, restrained, precise, low-noise interface.
- Subtle cyan/blue accents.
- No visual clutter, mascots, generic AI graphics, or excessive gradients.

Rules:
- Preserve existing visual identity.
- Improve spacing, alignment, hierarchy, and responsive behavior.
- Remove redundant text and awkward empty areas.
- Keep interactions clear and stable.
- Use CSS variables/design tokens when available.
- Avoid unnecessary dependencies.

Verification:
- Check affected routes visually.
- Test mobile/tablet/desktop.
- Check console.
