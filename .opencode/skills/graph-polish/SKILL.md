# Graph Polish

## Purpose

Improve knowledge graph clarity, layout, node interaction, edge readability, and visual organization.

## When To Use

Use for graph, node, edge, dependency, knowledge-map, and Obsidian-like visualization work.

## Core Rules

- Prioritize readability over complexity.
- Avoid tangled layouts and heavy overlap.
- Keep node interaction predictable.
- Reveal useful hover/selection context without clutter.
- Keep controls obvious and stable.
- Preserve NeuralVerse dark research aesthetics.

## Workflow

1. Inspect graph data, layout, renderer, and interaction scope.
2. Identify readability or interaction failure.
3. Apply the smallest layout or interaction improvement.
4. Validate visually when possible.

## Validation

- Check node spacing, edge readability, and label overlap.
- Check zoom, pan, reset, hover, focus, and selected states when relevant.
- Check mobile/tablet degradation for affected graph routes.

## Report

- Graph issue addressed.
- Files changed.
- Interaction states checked.
- Viewports or routes checked.
- Remaining graph risks.

## Forbidden

- Do not add visual complexity that reduces comprehension.
- Do not hide graph state behind unclear controls.
