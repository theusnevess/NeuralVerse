# Graph Polish Skill

Use this skill for graph, node, edge, dependency, knowledge-map, and Obsidian-like visualization work.

Rules:
- Prioritize readability over complexity.
- Avoid tangled layouts and heavy overlap.
- Node interaction must be predictable.
- Hover/selection should reveal useful context without clutter.
- Controls must be obvious.
- Keep graph aesthetics consistent with NeuralVerse dark research style.
- Validate using browser/Playwright when possible.

Check:
- Node spacing
- Edge readability
- Label overlap
- Zoom/pan/reset behavior
- Hover/focus/selection states
- Mobile/tablet degradation
