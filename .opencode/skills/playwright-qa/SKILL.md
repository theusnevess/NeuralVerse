# Playwright QA Skill

Use this skill for UI validation and regression testing.

Rules:
- Start or reuse the local dev/static server.
- Test relevant routes and affected UI states.
- Check desktop, tablet, and mobile widths.
- Inspect console errors and warnings.
- Validate keyboard accessibility where relevant.
- Validate hover/focus/selected states when relevant.
- Do not mark task complete if visual or console issues remain.

Required report:
- Routes tested
- Viewports tested
- Commands run
- Bugs found
- Bugs fixed
- Remaining risks
