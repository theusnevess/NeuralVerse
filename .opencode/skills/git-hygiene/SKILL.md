# Git Hygiene Skill

Use this skill before finalizing work.

Rules:
- Check git status before and after changes.
- Do not commit unless explicitly asked.
- Keep diffs focused.
- Do not include generated junk, caches, logs, screenshots, or test artifacts unless requested.
- Report changed files.
- Report commands run.
- Report tests passed/failed.
- Report unresolved risks.

Never claim a commit was made unless it was actually made.
