# NeuralVerse — Architecture Context

## Architecture Type

NeuralVerse is a static/frontend-first AI learning and research platform.

## Current Stack

- HTML
- CSS
- JavaScript
- React/Vite island where applicable

## Boundaries

- Do not introduce backend services unless explicitly requested.
- Do not introduce authentication unless explicitly requested.
- Do not introduce databases unless explicitly requested.
- Do not introduce external API dependencies unless explicitly requested.

## Main Areas

- App shell and navigation
- Learning modules and paths
- Retrieval workspace
- Knowledge graph visualization
- Settings and user preferences
- Visual system and reusable UI patterns

## Change Strategy

Prefer small, reversible changes. Preserve current architecture and design language.
