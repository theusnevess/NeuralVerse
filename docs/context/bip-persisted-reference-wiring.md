# BIP Persisted Reference Wiring

The workflow now executes curriculum, evidence and knowledge before the
parallel enrichment branches. Every later activity receives references from
the typed map. The agent activity reconstructs dependencies from canonical
PostgreSQL records before invoking the ACP assembler and returns only a stable
reference.

`LoadCanonicalActivityDependencies` is registered on the system queue for the
same reconstruction and verification boundary. Workflow code does not access
PostgreSQL. The implementation is a Stage 9 candidate until the real end-to-end
and restart evidence is executed.
