# NeuralVerse — Coding Standards

## General

- Keep code modular, readable, and testable.
- Prefer small focused changes.
- Do not add dependencies without clear need.
- Remove dead code and unused imports.
- Preserve existing naming and structure when reasonable.

## UI

- Maintain responsive behavior.
- Avoid horizontal overflow.
- Preserve keyboard navigation.
- Use clear focus and hover states.
- Avoid redundant labels and visual clutter.

## Validation

For UI changes, validate relevant routes and check browser console errors.
