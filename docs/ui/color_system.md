# NV-010 — Color System Definition

**Status:** APPROVED
**Phase:** UI Foundation
**Authority:** NeuralVerse HUB
**Date:** 2026-06-06

---

## Objective
Define the official color system of NeuralVerse.
The color system must support: Deep Focus, Scientific Professionalism, Long-Term Readability, Research Observatory identity, Future scalability.
This decision is governed by: Vision, UI Constitution, Architecture Guide, and NV-009 Brand System.

---

## Design Rationale
Color is not decorative. Color exists to provide: Hierarchy, State communication, Discovery, Navigation guidance.
Color must never become visual noise. The platform should feel like: "A modern AI research laboratory." (Not gaming, cyberpunk, corporate dashboard, or social media).

---

## Official Direction
**Approved Visual Direction:** `Research Observatory Final`
Combines: Deep Graphite Observatory + Scientific Slate
Preserves: Scientific Cyan accent strategy, Laboratory semantic indicators, Deep dark environment, Premium visual atmosphere.

---

## Visual Reference
**Official visual reference:** `NeuralVerse Visual Reference v1`
Purpose: Style reference, Mood reference, Atmosphere reference.
Not: Final page layout, Final dashboard, Final screen implementation.

---

## Dark Foundation
### Base Layer
Purpose: Primary application background.
Characteristics: Deep graphite, Extremely low visual noise, Comfortable for long reading sessions, Observatory atmosphere.
Target feeling: Scientific instrument. Not terminal. Not gaming.

---

## Surface Hierarchy
Recommended structure:
* Level 0: Application Background
* Level 1: Panels
* Level 2: Cards
* Level 3: Elevated Cards
* Level 4: Modal Surfaces
* Level 5: Priority Surfaces

Requirements: Clear separation, Minimal visual clutter, Consistent elevation progression.

---

## Accent Strategy
**Official Accent Family:** `Scientific Cyan`
Purpose: Discovery, Active states, Navigation guidance, Interactive elements, Focus indicators.
Brand alignment: Precision, Observation, Engineering, Scientific exploration.
Forbidden: Neon cyan, RGB glow aesthetics, Cyberpunk effects. Accent must remain controlled.

---

## Semantic System
Semantic colors must behave like laboratory indicators. (Not mobile notifications or consumer alerts).
Categories:
* `Success (Stable)`
* `Warning (Anomaly)`
* `Error (Critical)`
* `Information (Data)`

Characteristics: Slightly desaturated, Professional, Functional, High contrast.

---

## Contrast Philosophy
Priority order:
1. Readability
2. Accessibility
3. Hierarchy
4. Aesthetics
*(Never the reverse)*

Requirements: AAA where possible, AA minimum for interactive content, Long-session comfort, Reduced eye fatigue.

---

## Approved Characteristics
Approved: Deep graphite foundation, Cyan scientific accent, Thin iconography, Soft borders, Layered surfaces, Observatory atmosphere, Premium dark mode, Scientific visual language.

## Implementation Restrictions
Implementation must reduce:
* Approximately 40% less glow.
* Approximately 30% fewer decorative lines.
* Approximately 50% less simultaneous visual density.

Reason: Content First. Clarity Before Decoration.
