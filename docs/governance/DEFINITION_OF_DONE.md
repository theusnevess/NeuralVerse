# DEFINITION_OF_DONE.md

## Purpose

This document defines the canonical completion standard for NeuralVerse implementation work.

A feature is not done until every required governance gate passes.

---

## Architecture Done

Done only if:

```text
Canonical hierarchy respected.
Architecture Guide respected.
No unauthorized technology introduced.
No scope violation introduced.
```

---

## Design System Done

Done only if:

```text
Registry entry exists.
Approved tokens used.
No hardcoded design values.
Component contract followed.
```

---

## Navigation Done

Done only if:

```text
Navigation contract exists.
Hierarchy is preserved.
Keyboard behavior is defined.
Responsive behavior is defined.
```

---

## Accessibility Done

Done only if:

```text
Accessibility Matrix entry exists.
Keyboard requirements pass.
Focus requirements pass.
Semantic requirements pass.
Screen-reader requirements pass.
Reduced-motion requirements pass where applicable.
```

---

## Motion Done

Done only if:

```text
Motion Registry entry exists.
Motion serves clarity or continuity.
Reduced-motion variant exists.
Disabled-motion behavior exists.
```

---

## Documentation Done

Done only if:

```text
Registry updated.
Contract updated.
Change log updated.
Review status recorded.
```

---

## Governance Done

Done only if:

```text
All gates passed.
No unresolved blockers remain.
HUB escalation completed when required.
```

---

## Phase 1 Completion Meaning

For Phase 1, “complete” does not mean product-ready.

It means:

```text
Architecture-compliant
Registry-backed
Token-driven
Accessibility-validated
Motion-governed
Documentation-updated
```
