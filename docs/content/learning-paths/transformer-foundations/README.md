# Transformer Foundations

*   **Learning Path ID:** `path-transformer-foundations`
*   **Status:** `Draft`
*   **Path Type:** `Foundational Learning Path`

## Learning Path Aim

Introduce learners to the conceptual foundations of the Transformer architecture, including attention parallelization, scaled Query-Key-Value operations, multi-head attention subspaces, sinusoidal positional encoding, encoder/decoder causal masking, and subword tokenization representations.

*   [Transformer Fundamentals](../../modules/transformer-fundamentals/) (`module-transformer-fundamentals`)

## Evidence Boundary Reminder

This Learning Path organizes Modules. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.
