# AI Agents & Tool Use Foundations — Learning Path Composition

## 1. Purpose

This Learning Path organizes multiple Modules into a coherent, high-level AI Agents & Tool Use curriculum progression.

It serves as an organizational and navigational guide for learners. The Learning Path does not duplicate, embed, or rewrite the content of the referenced modules, lessons, or learning artifacts.

## 2. Learning Path Aim

Introduce learners to the conceptual foundations of AI agents and external actions, including perception-action loops, ReAct planning and task decomposition, function schema validation and tool calling, short-term vs. long-term memory configurations, self-correcting critique loops, and collaborative multi-agent patterns.

This path focuses on agent architectures, without claiming or certifying competency mastery.

## 3. Included Modules

### 3.1 Agent Fundamentals

*   **Module ID:** `module-agent-fundamentals`
*   **Location:** `docs/content/modules/agent-fundamentals/module-composition.md`
*   **Pedagogical Role:** Establishes perception-action loops, sub-goal generation, and parameter schema validations.
*   **Relationship to Learning Path Aim:** Satisfies the initial step of the learning path's aim by exposing the learner to loop configurations and tool interfaces.

### 3.2 Agent Memory & Orchestration

*   **Module ID:** `module-agent-memory-orchestration`
*   **Location:** `docs/content/modules/agent-memory-orchestration/module-composition.md`
*   **Pedagogical Role:** Details memory systems, critique-feedback loops, and specialized persona routes.
*   **Relationship to Learning Path Aim:** Deepens understanding of context persistence and robust cooperative agency.

This learning path does not duplicate any of the instructional content or text from the module compositions themselves.

## 4. Learning Path Flow

The learning path structures the following module progression:

1.  **Agent Fundamentals** (`module-agent-fundamentals`)
2.  **Agent Memory & Orchestration** (`module-agent-memory-orchestration`)

### Future Expansion

Future modules may extend this path with topics such as advanced web search tools, database execution loops, sandboxed environments, or autonomous multi-agent environments.

*Note: These future modules and future module stubs are not created or defined in this phase.*
