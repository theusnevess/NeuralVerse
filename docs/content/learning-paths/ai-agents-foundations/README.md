# AI Agents & Tool Use Foundations

*   **Learning Path ID:** `path-ai-agents-foundations`
*   **Status:** `Draft`
*   **Path Type:** `Foundational Learning Path`

## Learning Path Aim

Introduce learners to the conceptual foundations of AI agents and external actions, including perception-action loops, ReAct planning and task decomposition, function schema validation and tool calling, short-term vs. long-term memory configurations, self-correcting critique loops, and collaborative multi-agent patterns.

This Learning Path organizes Modules. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.
