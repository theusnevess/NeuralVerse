# Object Detection Foundations

*   **Learning Path ID:** `path-object-detection-foundations`
*   **Status:** `Draft`
*   **Path Type:** `Foundational Learning Path`

## Learning Path Aim

Introduce learners to classification-regression multi-task networks, coordinate box systems, Jaccard Index overlap ratios, anchor setups, non-maximum peak score suppression loops, and single-stage vs. multi-stage proposals.

## Included Modules

*   [Detection Fundamentals](../../modules/detection-fundamentals/) (`module-detection-fundamentals`)
*   [Detection Architectures](../../modules/detection-architectures/) (`module-detection-architectures`)

## Evidence Boundary Reminder

This Learning Path organizes Modules. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future modules may extend this path with topics such as transformer-based detection heads (DETR, RT-DETR), Feature Pyramid Networks (FPN), or Soft-NMS algorithms.
