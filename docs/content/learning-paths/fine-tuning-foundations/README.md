# Fine-Tuning & Adaptation Foundations

*   **Learning Path ID:** `path-fine-tuning-foundations`
*   **Status:** `Draft`
*   **Path Type:** `Foundational Learning Path`

## Learning Path Aim

Introduce learners to the conceptual foundations of model adaptation, including gradient updates, instruction alignment, Parameter-Efficient Fine-Tuning (PEFT/LoRA), SFT loss masking, Reinforcement Learning from Human Feedback (RLHF), and domain specialization.

## Included Modules

*   [Model Adaptation Fundamentals](../../modules/model-adaptation/) (`module-model-adaptation`)
*   [Alignment & Specialization](../../modules/alignment-specialization/) (`module-alignment-specialization`)

## Evidence Boundary Reminder

This Learning Path organizes Modules. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.
