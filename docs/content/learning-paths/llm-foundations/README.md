# Large Language Model Foundations

*   **Learning Path ID:** `path-llm-foundations`
*   **Status:** `Draft`
*   **Path Type:** `Foundational Learning Path`

## Learning Path Aim

Introduce learners to the conceptual foundations of Large Language Models (LLMs), including scaling laws, autoregressive sampling decoding, prompt shaping, KV caching limits, In-Context Learning activation states, and hallucination alignment mitigations.

## Included Modules

*   [LLM Core Concepts](../../modules/llm-core/) (`module-llm-core`)
*   [LLM Context & Behavior](../../modules/llm-context-behavior/) (`module-llm-context-behavior`)

## Evidence Boundary Reminder

This Learning Path organizes Modules. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.
