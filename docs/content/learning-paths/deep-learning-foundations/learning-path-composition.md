# Deep Learning Foundations — Learning Path Composition

## 1. Purpose

This Learning Path organizes multiple Modules into a coherent, high-level deep learning curriculum progression.

It serves as an organizational and navigational guide for learners. The Learning Path does not duplicate, embed, or rewrite the content of the referenced modules, lessons, or learning artifacts.

## 2. Learning Path Aim

Introduce learners to the core architecture, optimization, and training protocols of deep artificial neural networks, building upon mathematical representation and machine learning structures.

This path focuses on neural networks and gradient updates, without claiming or certifying competency mastery.

## 3. Included Modules

### 3.1 Neural Network Fundamentals

*   **Module ID:** `module-neural-network-fundamentals`
*   **Location:** `docs/content/modules/neural-network-fundamentals/module-composition.md`
*   **Pedagogical Role:** Establishes neuron layouts, forward calculations, and non-linear thresholds.
*   **Relationship to Learning Path Aim:** Satisfies the initial step of the learning path's aim by exposing the learner to core neuron topologies, forward inference flows, and activation functions.

### 3.2 Optimization and Training

*   **Module ID:** `module-optimization-training`
*   **Location:** `docs/content/modules/optimization-training/module-composition.md`
*   **Pedagogical Role:** Focuses on backward error sweeps (backpropagation), optimization descent (SGD/Adam), and training hyperparameters.
*   **Relationship to Learning Path Aim:** Deepens understanding of network learning adjustments and hyperparameter schedules.

This learning path does not duplicate any of the instructional content or text from the module compositions themselves.

## 4. Learning Path Flow

The learning path structures the following module progression:

1.  **Neural Network Fundamentals** (`module-neural-network-fundamentals`)
2.  **Optimization and Training** (`module-optimization-training`)

### Future Expansion

Future modules may extend this path with topics such as sequence models (RNNs/LSTMs), transformer architectures, generative adversarial structures, or distributed inference scalability.

*Note: These future modules and future module stubs are not created or defined in this phase.*
