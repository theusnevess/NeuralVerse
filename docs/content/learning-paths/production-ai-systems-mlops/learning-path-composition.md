# Production AI Systems and MLOps — Learning Path Composition

## 1. Purpose

This Learning Path organizes multiple Modules into a coherent, high-level Production AI Systems and MLOps curriculum progression.

It serves as an organizational and navigational guide for learners. The Learning Path does not duplicate, embed, or rewrite the content of the referenced modules, lessons, or learning artifacts.

## 2. Learning Path Aim

Introduce learners to production AI systems and MLOps, including model serving and inference optimization, monitoring and observability, data and concept drift detection, ML pipelines and orchestration, model versioning and experiment tracking, and deployment strategies with rollback mechanisms.

This path focuses on equipping learners with the conceptual tools to design, evaluate, and operate production AI systems, without claiming or certifying competency mastery.

## 3. Included Modules

### 3.1 Production AI Systems

*   **Module ID:** `module-production-ai-systems`
*   **Location:** `docs/content/modules/production-ai-systems/module-composition.md`
*   **Pedagogical Role:** Establishes core production AI concepts: model serving and inference, monitoring and observability, and drift detection.
*   **Relationship to Learning Path Aim:** Satisfies the production AI systems step of the learning path's aim.

### 3.2 MLOps Lifecycle

*   **Module ID:** `module-mlops-lifecycle`
*   **Location:** `docs/content/modules/mlops-lifecycle/module-composition.md`
*   **Pedagogical Role:** Deepens MLOps lifecycle concepts: ML pipelines and orchestration, model versioning and experiment tracking, and deployment strategies with rollbacks.
*   **Relationship to Learning Path Aim:** Covers the MLOps lifecycle step of the learning path's aim.

This learning path does not duplicate any of the instructional content or text from the module compositions themselves.

The learning path structures the following module progression:
