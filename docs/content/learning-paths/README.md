# Learning Paths

This directory contains draft NeuralVerse learning path compositions.

Learning Paths organize Modules into coherent curriculum-level progressions. They represent the highest organizational level of the NeuralVerse learning ecosystem.

## Key Rules

*   **No Mastery Certification:** Learning paths do not certify mastery.
*   **No Competency Evidence:** Learning paths do not generate Competency Evidence.
*   **No Content Duplication:** Learning paths do not duplicate the actual learning content or text from modules, lessons, or learning artifacts.
