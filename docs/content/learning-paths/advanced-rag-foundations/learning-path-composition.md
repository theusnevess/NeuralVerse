# Advanced RAG Foundations — Learning Path Composition

## 1. Purpose

This Learning Path organizes multiple Modules into a coherent, high-level Advanced Retrieval & RAG Systems curriculum progression.

It serves as an organizational and navigational guide for learners. The Learning Path does not duplicate, embed, or rewrite the content of the referenced modules, lessons, or learning artifacts.

## 2. Learning Path Aim

Introduce learners to advanced Retrieval-Augmented Generation architectures, including query intent routing, Reciprocal Rank Fusion (RRF) context aggregation, hybrid BM25/vector/metadata indexing, iterative Self-RAG and Corrective RAG (CRAG) loops, knowledge grounding and citation attribution, and retrieval failure modes with engineering mitigations.

This path focuses on system-level RAG engineering, without claiming or certifying competency mastery.

## 3. Included Modules

### 3.1 Advanced Retrieval Pipelines

*   **Module ID:** `module-advanced-retrieval-pipelines`
*   **Location:** `docs/content/modules/advanced-retrieval-pipelines/module-composition.md`
*   **Pedagogical Role:** Establishes query routing rules, RRF math, and hybrid index scan patterns.
*   **Relationship to Learning Path Aim:** Satisfies the initial pipeline engineering step of the learning path's aim.

### 3.2 Agentic Retrieval Systems

*   **Module ID:** `module-agentic-retrieval-systems`
*   **Location:** `docs/content/modules/agentic-retrieval-systems/module-composition.md`
*   **Pedagogical Role:** Deepens retrieval architecture via iterative Self-RAG loops, grounding schemas, and failure typologies.
*   **Relationship to Learning Path Aim:** Covers the agentic and reliability layer of the learning path's aim.

This learning path does not duplicate any of the instructional content or text from the module compositions themselves.

## 4. Learning Path Flow

The learning path structures the following module progression:

1.  **Advanced Retrieval Pipelines** (`module-advanced-retrieval-pipelines`)
2.  **Agentic Retrieval Systems** (`module-agentic-retrieval-systems`)

### Future Expansion

Future modules may extend this path with topics such as graph-based retrieval, streaming RAG pipelines, or multi-modal hybrid retrieval.

*Note: These future modules are not created or defined in this phase.*
