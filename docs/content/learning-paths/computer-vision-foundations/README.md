# Computer Vision Foundations

*   **Learning Path ID:** `path-computer-vision-foundations`
*   **Status:** `Draft`
*   **Path Type:** `Foundational Learning Path`

## Learning Path Aim

Introduce learners to the spatial, channel, and mathematical representations of digital images, convolution operations, Sobel filter feature maps, and classical vs deep learning paradigms.

*   [Image Representation Foundations](../../modules/image-representation-foundations/) (`module-image-representation-foundations`)
*   [Visual Feature Extraction Foundations](../../modules/visual-feature-extraction-foundations/) (`module-visual-feature-extraction-foundations`)

## Evidence Boundary Reminder

This Learning Path organizes Modules. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future modules may extend this path with topics such as Convolutional Neural Networks (CNNs), object detection grids (YOLO), semantic segmentation masks, optical character recognition (OCR), Vision Transformers (ViTs), or multimodal CLIP representations.
