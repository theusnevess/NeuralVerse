# Computer Vision Foundations — Learning Path Composition

## 1. Purpose

This Learning Path organizes multiple Modules into a coherent, high-level computer vision curriculum progression.

It serves as an organizational and navigational guide for learners. The Learning Path does not duplicate, embed, or rewrite the content of the referenced modules, lessons, or learning artifacts.

## 2. Learning Path Aim

Introduce learners to the spatial, channel, and mathematical representations of digital images, convolution operations, Sobel filter feature maps, and classical vs deep learning paradigms.

This path focuses on visual matrices and filter operations, without claiming or certifying competency mastery.

## 3. Included Modules

### 3.1 Image Representation Foundations

*   **Module ID:** `module-image-representation-foundations`
*   **Location:** `docs/content/modules/image-representation-foundations/module-composition.md`
*   **Pedagogical Role:** Establishes pixel grids, color spaces, channel tensors, and resizing interpolations.
*   **Relationship to Learning Path Aim:** Satisfies the initial step of the learning path's aim by exposing the learner to image matrices, color space formats, and spatial resizing interpolation details.

### 3.2 Visual Feature Extraction Foundations

*   **Module ID:** `module-visual-feature-extraction-foundations`
*   **Location:** `docs/content/modules/visual-feature-extraction-foundations/module-composition.md`
*   **Pedagogical Role:** Details sliding convolutions (strides/padding), Sobel/blur feature maps, and handcrafted vs learned pipelines.
*   **Relationship to Learning Path Aim:** Deepens understanding of filtering operations, visual gradients, and representation learning paradigm shifts.

This learning path does not duplicate any of the instructional content or text from the module compositions themselves.

## 4. Learning Path Flow

The learning path structures the following module progression:

1.  **Image Representation Foundations** (`module-image-representation-foundations`)
2.  **Visual Feature Extraction Foundations** (`module-visual-feature-extraction-foundations`)

### Future Expansion

Future modules may extend this path with topics such as Convolutional Neural Networks (CNNs), object detection grids (YOLO), semantic segmentation masks, optical character recognition (OCR), Vision Transformers (ViTs), or multimodal CLIP representations.

*Note: These future modules and future module stubs are not created or defined in this phase.*
