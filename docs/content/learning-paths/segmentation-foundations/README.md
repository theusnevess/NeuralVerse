# Segmentation Foundations

*   **Learning Path ID:** `path-segmentation-foundations`
*   **Status:** `Draft`
*   **Path Type:** `Foundational Learning Path`

## Learning Path Aim

Introduce learners to image segmentation paradigms, including category-level pixel grouping, output logit classification heads, one-hot map formats, encoder-decoder bottlenecks, skip connection spatial restores, and U-Net vs. Mask R-CNN architectural distinctions.

## Included Modules

*   [Segmentation Fundamentals](../../modules/segmentation-fundamentals/) (`module-segmentation-fundamentals`)
*   [Segmentation Architectures](../../modules/segmentation-architectures/) (`module-segmentation-architectures`)

## Evidence Boundary Reminder

This Learning Path organizes Modules. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future modules may extend this path with topics such as Feature Pyramid Networks (FPN), dilated/atrous convolutions (DeepLab), or transformer-based segmentation models (Mask2Former).
