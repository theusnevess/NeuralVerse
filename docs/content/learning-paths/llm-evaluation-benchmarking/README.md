# LLM Evaluation and Benchmarking

*   **Learning Path ID:** `path-llm-evaluation-benchmarking`
*   **Status:** `Draft`
*   **Path Type:** `Foundational Learning Path`

## Learning Path Aim

Introduce learners to comprehensive LLM evaluation and benchmarking methodologies, including automatic evaluation metrics (BLEU, ROUGE, METEOR, BERTScore), human evaluation protocols (fluency, coherence, factuality, annotation agreement), task-specific benchmarking (MMLU, GSM8K, HumanEval, BIG-bench), RAG evaluation frameworks (faithfulness, context precision, context recall, answer relevance), hallucination detection and analysis (intrinsic vs. extrinsic, grounding, verifiability), and agent evaluation methodologies (planning, tool use, multi-step execution, robustness).
