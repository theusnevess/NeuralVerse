# LLM Evaluation and Benchmarking — Learning Path Composition

## 1. Purpose

This Learning Path organizes multiple Modules into a coherent, high-level LLM Evaluation and Benchmarking curriculum progression.

It serves as an organizational and navigational guide for learners. The Learning Path does not duplicate, embed, or rewrite the content of the referenced modules, lessons, or learning artifacts.

## 2. Learning Path Aim

Introduce learners to comprehensive LLM evaluation and benchmarking methodologies, including automatic evaluation metrics (BLEU, ROUGE, METEOR, BERTScore), human evaluation protocols (fluency, coherence, factuality, annotation agreement), task-specific benchmarking (MMLU, GSM8K, HumanEval, BIG-bench), RAG evaluation frameworks (faithfulness, context precision, context recall, answer relevance), hallucination detection and analysis (intrinsic vs. extrinsic, grounding, verifiability), and agent evaluation methodologies (planning, tool use, multi-step execution, robustness).

This path focuses on equipping learners with the conceptual tools to design, interpret, and critique LLM evaluation strategies, without claiming or certifying competency mastery.

## 3. Included Modules

### 3.1 LLM Evaluation Fundamentals

*   **Module ID:** `module-llm-evaluation-fundamentals`
*   **Location:** `docs/content/modules/llm-evaluation-fundamentals/module-composition.md`
*   **Pedagogical Role:** Establishes the foundational evaluation paradigms: automatic metrics, human annotation, and benchmark design.
*   **Relationship to Learning Path Aim:** Satisfies the foundational evaluation knowledge step of the learning path's aim.

### 3.2 RAG & Agent Evaluation

*   **Module ID:** `module-rag-agent-evaluation`
*   **Location:** `docs/content/modules/rag-agent-evaluation/module-composition.md`
*   **Pedagogical Role:** Deepens evaluation concepts for RAG pipelines, hallucination detection, and AI agent systems.
*   **Relationship to Learning Path Aim:** Covers the applied evaluation layer for production AI systems.

This learning path does not duplicate any of the instructional content or text from the module compositions themselves.
