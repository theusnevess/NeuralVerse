# AI Research and Frontier Topics — Learning Path Composition

## 1. Purpose

This Learning Path organizes multiple Modules into a coherent, high-level AI Research and Frontier Topics curriculum progression.

It serves as an organizational and navigational guide for learners. The Learning Path does not duplicate, embed, or rewrite the content of the referenced modules, lessons, or learning artifacts.

## 2. Learning Path Aim

Introduce learners to frontier AI research: scaling laws, reasoning models, MoE architectures, world models, neurosymbolic AI, and AI for scientific discovery. Focus on enduring research principles rather than specific models or benchmarks.

This path focuses on equipping learners with the conceptual tools to understand frontier AI research directions, without claiming or certifying competency mastery.

## 3. Included Modules

### 3.1 Frontier Model Scaling

*   **Module ID:** `module-frontier-model-scaling`
*   **Location:** `docs/content/modules/frontier-model-scaling/module-composition.md`
*   **Pedagogical Role:** Covers scaling laws, reasoning models, and mixture-of-experts architectures.
*   **Relationship to Learning Path Aim:** Satisfies the frontier model scaling step of the learning path's aim.

### 3.2 Frontier AI Paradigms

*   **Module ID:** `module-frontier-ai-paradigms`
*   **Location:** `docs/content/modules/frontier-ai-paradigms/module-composition.md`
*   **Pedagogical Role:** Covers world models and latent simulation, neurosymbolic AI, and AI for scientific discovery.
*   **Relationship to Learning Path Aim:** Covers the frontier AI paradigms step of the learning path's aim.

This learning path does not duplicate any of the instructional content or text from the module compositions themselves.
