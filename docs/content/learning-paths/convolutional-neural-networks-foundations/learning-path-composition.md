# Convolutional Neural Networks Foundations — Learning Path Composition

## 1. Purpose

This Learning Path organizes multiple Modules into a coherent, high-level convolutional neural network curriculum progression.

It serves as an organizational and navigational guide for learners. The Learning Path does not duplicate, embed, or rewrite the content of the referenced modules, lessons, or learning artifacts.

## 2. Learning Path Aim

Introduce learners to the architectural components, spatial downsampling methods, receptive field calculations, layered visual hierarchies, and transfer learning backbones of Convolutional Neural Networks.

This path focuses on translation invariance and feature reuse, without claiming or certifying competency mastery.

## 3. Included Modules

### 3.1 CNN Building Blocks

*   **Module ID:** `module-cnn-building-blocks`
*   **Location:** `docs/content/modules/cnn-building-blocks/module-composition.md`
*   **Pedagogical Role:** Establishes local connectivity, parameter sharing, pooling downsamplings, and stride/padding shape equations.
*   **Relationship to Learning Path Aim:** Satisfies the initial step of the learning path's aim by exposing the learner to parameter scaling, spatial downsamplings, and stride/padding dimension maps.

### 3.2 Representation Learning in CNNs

*   **Module ID:** `module-representation-learning-cnns`
*   **Location:** `docs/content/modules/representation-learning-cnns/module-composition.md`
*   **Pedagogical Role:** Details receptive field growth steps, Gabor edge-to-object conversions, and frozen pretrained backbone runs.
*   **Relationship to Learning Path Aim:** Deepens understanding of layered contextual abstraction, visual hierarchies, and transfer learning adaptations.

This learning path does not duplicate any of the instructional content or text from the module compositions themselves.

## 4. Learning Path Flow

The learning path structures the following module progression:

1.  **CNN Building Blocks** (`module-cnn-building-blocks`)
2.  **Representation Learning in CNNs** (`module-representation-learning-cnns`)

### Future Expansion

Future modules may extend this path with topics such as object detection boundaries, image segmentation maps (U-Net), generative adversarial vision setups, or downstream optical character recognition systems.

*Note: These future modules and future module stubs are not created or defined in this phase.*
