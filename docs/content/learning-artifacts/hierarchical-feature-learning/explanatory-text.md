# Hierarchies of Visual Abstraction

## Artifact Summary

This artifact belongs to the Hierarchical Feature Learning topic and serves as a Explanatory Text.

## Required Contract Fields

### objective

Explain deep network visual abstractions and visual cortex analogies.

### explanation

CNNs learn feature hierarchies automatically. In early layers, filters respond to simple, localized visual gradients (like edges, corners, and color spots), resembling Gabor filters. In middle layers, these simple features combine to detect abstract textures and parts of objects (like wheels, eyes, or mesh patterns). In deep layers, the network combines parts to detect complete semantic objects (like cars, faces, or dogs). This hierarchy mirrors the human visual cortex, moving from local pixel gradients to global semantic representations.
