# Draft Editing and Typo Checks

## Artifact Summary

This artifact belongs to the Reflection and Self-Correction topic and serves as a Visual Intuition.

## Required Contract Fields

### objective

Provide an analogy based on review cycles before finalization.

### explanation

Imagine writing an essay. A static LLM is like typing the essay from top to bottom and handing it in without reading it. An agent with reflection is like writing a draft, reading it over to highlight typos and weak arguments (critique), and rewriting those specific sections before submitting the final paper.
