# Visualizing Continuous vs. Discrete Outlines

## Artifact Summary

Uses analogy and mental models to build intuition about Visualizing Continuous vs. Discrete Outlines — maps familiar concepts to the technical mechanics of Random Variables, making abstract ideas concrete.

## Required Contract Fields

### objective

Provide a visual distinction between slotted wheels (discrete) and continuous dial spinners (continuous).

### explanation

Imagine a prize wheel. If the wheel has slots labeled '1st', '2nd', '3rd', the prize rank is a discrete random variable. If the wheel is a smooth circle and you measure the exact angle where it stops (e.g., 142.35 degrees), the angle is a continuous random variable.
