# Discrete and Continuous Random Variables

## Artifact Summary

This artifact belongs to the Random Variables topic and serves as a Explanatory Text.

## Required Contract Fields

### objective

Explain random variables as mappings from sample outcomes to numerical values, comparing discrete and continuous types.

### explanation

In artificial intelligence and machine learning, uncertainty is modeled using random variables. A random variable maps outcomes of a random process to real numbers: 1. Discrete Random Variables: Take on countable distinct values (e.g., predicted classification labels: 0, 1, or 2; or token counts). 2. Continuous Random Variables: Take on any value in an interval (e.g., retrieval similarity score, model prediction probability between 0.0 and 1.0, or neural network weights). These variables allow us to calculate expectations and probabilities of specific events.
