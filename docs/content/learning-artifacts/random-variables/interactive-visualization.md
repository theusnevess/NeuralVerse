Specifies an interactive tool for exploring Random Variable Simulator Spec — describes the controls, visual feedback, and conceptual relationships a learner would manipulate to understand Random Variables.

## Required Contract Fields

### objective

Specify an interactive playground comparing discrete histograms to continuous bell curves.

### explanation

This specification describes a random variable simulator. The user flips a coin multiple times (discrete) or sample points from a noisy temperature sensor (continuous). The tool displays the outcomes in a histogram, visualizing how discrete bars differ from a continuous curve.
