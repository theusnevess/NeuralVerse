Specifies an interactive tool for exploring Attention Matrix Simulator Spec — describes the controls, visual feedback, and conceptual relationships a learner would manipulate to understand Self-Attention Mechanism.

This specification outlines an attention matrix visualizer. The user types a simple sentence like 'The bank of the river' vs. 'The money bank' and hovers over words to see the query-key dot-product connection lines glow.
