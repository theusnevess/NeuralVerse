# Filter Weight Applicator Spec

## Artifact Summary

This artifact belongs to the Feature Maps and Filters topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify a custom 3x3 weight applicator and output renderer.

### explanation

This specification describes a filter builder. The user types custom weights into a 3 x 3 kernel grid (e.g., Sobel values) and applies it to a sample image to watch vertical edges, horizontal edges, or blurs render instantly.

## Optional Enrichment Fields
