# Classical vs. Deep Learning Vision

## Artifact Summary

Compares key approaches, algorithms, or architectures within Classical Computer Vision vs Deep Learning Vision — organizes Classical vs. Deep Learning Vision into a structured reference for selecting between alternatives.

### objective

Compare SIFT/HOG pipelines with learned CNN weights across data, compute, and explainability.

### explanation

| Metric | Classical Computer Vision | Deep Learning Computer Vision |
|---|---|---|
| Feature Extraction | Hand-crafted (e.g., SIFT, HOG) | Learned automatically (end-to-end) |
| Dataset Size Requirement | Small (tens to hundreds of images) | Large (thousands to millions) |
| Interpretability | High (known mathematical filters) | Low (black-box learned parameters) |
| Hardware Requirement | Low CPU | High GPU / TPU |
