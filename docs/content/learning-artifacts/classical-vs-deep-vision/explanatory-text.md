# Vision Paradigms Comparison

## Artifact Summary

This artifact belongs to the Classical Computer Vision vs Deep Learning Vision topic and serves as a Explanatory Text.

## Required Contract Fields

### objective

Explain manual features vs. end-to-end representations and computation needs.

### explanation

Computer vision has evolved through two primary paradigms: 1. Classical Computer Vision: Relies on manual feature engineering (e.g., designing SIFT, HOG, or Canny Edge detectors) followed by a simple classifier. It requires domain expertise, works with small datasets, but fails on complex scenes. 2. Deep Learning Vision: Uses end-to-end representation learning (e.g., CNNs or Vision Transformers). The model learns both the filters and the classifier simultaneously from raw pixels. It requires massive data and GPU power but achieves superior accuracy.
