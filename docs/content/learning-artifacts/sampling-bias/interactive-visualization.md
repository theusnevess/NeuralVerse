# Sampling Simulator Spec

## Artifact Summary

This artifact belongs to the Sampling and Sampling Bias topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive dot drawing tool comparing random, stratified, and biased sampling averages.

### explanation

This specification describes a sampling bias simulator. The user draws samples from a population (represented by colored dots) using different sampling methods (Random, Stratified, Biased). The tool shows the estimated mean vs. the true population mean, highlighting the skew introduced by bias.
