# Tensor Shape Explorer Spec

## Artifact Summary

This artifact belongs to the Scalars, Vectors, Matrices, and Tensors topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive tool showing nested shapes based on dimensionality sliders.

### explanation

This specification describes a tensor shape explorer. The user increases dimensions (0D to 4D) and adjusts the size of each axis. The tool visualizes the data layout (a dot, a line of dots, a grid of dots, a 3D block, or a sequence of blocks) and generates the corresponding shape tuple (e.g., [3, 224, 224]).
