## Required Contract Fields

### objective

Explain scalars, vectors, matrices, and tensors as multi-dimensional numerical arrays.

### explanation

In machine learning and deep learning, all data is represented as numerical arrays of different dimensions: 1. Scalar (0D tensor): A single number, representing a single magnitude (e.g., temperature). 2. Vector (1D tensor): A 1D array of numbers, representing a coordinate or point in space (e.g., word embeddings). 3. Matrix (2D tensor): A 2D array of numbers with rows and columns, representing datasets, weights, or transformations. 4. Tensor (nD tensor): A multi-dimensional array (e.g., a color image represented as a 3D tensor of height, width, and color channels).
