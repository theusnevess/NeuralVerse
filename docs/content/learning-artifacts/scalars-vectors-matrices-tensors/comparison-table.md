# Tensor Ranks and Dimensions Reference

## Artifact Summary

This artifact belongs to the Scalars, Vectors, Matrices, and Tensors topic and serves as a Comparison Table.

## Required Contract Fields

### objective

Compare ranks, analogies, and typical use cases of tensor data types.

### explanation

| Structure | Rank (Dimensions) | Visual Analogy | AI Engineering Use Case |
|---|---|---|---|
| Scalar | 0D | A single point | Loss value, learning rate |
| Vector | 1D | A straight line | Single token/word embedding |
| Matrix | 2D | A flat sheet | Batch of embeddings, weight layer |
| Tensor | 3D+ | A volumetric block | Batch of color images, video frames |
