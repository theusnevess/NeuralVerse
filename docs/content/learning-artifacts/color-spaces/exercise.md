# Calculating Image Tensor Volumes

## Artifact Summary

Provides practice applying the concepts of Calculating Image Tensor Volumes — guides the learner through reasoning steps that reinforce understanding of Image Channels and Color Spaces through active problem-solving.

## Required Contract Fields

### objective

Calculate coordinate capacities across 3D image tensor dimensions.

### learner task

A color image tensor has shape $224 \times 224 \times 3$. Calculate: 1. The total number of pixels in a single channel. 2. The total number of numerical intensity values in the entire tensor.

### expected learner output

The learner should reason through the problem step by step, showing their work for each part. The expected output illustrates the reasoning format but not the complete solution.

This practice does not assign a score and does not certify mastery.
