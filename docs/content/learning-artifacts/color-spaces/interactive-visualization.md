# Channel Decomposition Spec

## Artifact Summary

This artifact belongs to the Image Channels and Color Spaces topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify a channel toggle board decomposing color dimensions.

### explanation

This specification outlines a channel decomposition tool. The user uploads a color image and uses sliders to toggle Red, Green, Blue, Hue, Saturation, and Value channels on/off, watching the reconstructed image update in real-time.
