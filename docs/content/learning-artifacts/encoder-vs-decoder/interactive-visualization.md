# Information Flow Map Spec

## Artifact Summary

This artifact belongs to the Encoder vs Decoder Architectures topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify a model tracing directional routing in BERT vs GPT.

### explanation

This specification outlines an information flow diagram. The user clicks buttons to toggle between 'Bidirectional BERT' (lines connecting all tokens in all directions) and 'Causal GPT' (lines pointing backward only).

## Optional Enrichment Fields

Understanding Transformers is critical for building modern LLMs (GPT-4, Llama), semantic search retrievers, RAG interfaces, and Vision Transformers.
