# Visualizing Query Expansion Paths

## Artifact Summary

This artifact belongs to the Query Expansion and Reformulation topic and serves as a Visual Intuition.

## Required Contract Fields

### objective

Build intuition on how query rewriting aligns with target document spaces.

### explanation

Imagine asking a librarian: 'Where is the stuff about the cold war computer game?' The librarian reformulates that in their mind to: 'History of early computing, chess simulations, geopolitical games'. That expansion helps them locate the correct shelf, whereas search by your exact words might fail.
