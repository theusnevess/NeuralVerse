# Highlighting Apple Conveyor Belts

## Artifact Summary

Uses analogy and mental models to build intuition about Highlighting Apple Conveyor Belts — maps familiar concepts to the technical mechanics of Object Detection Fundamentals, making abstract ideas concrete.

## Required Contract Fields

### objective

Provide an analogy based on conveyor belt object counts and gripper coordinates.

### explanation

Imagine an inspector checking a factory belt. If they only count how many apples pass by, they are doing classification. If they also draw a glowing highlight box around each apple to track its location for a robotic arm to grab, they are performing object detection. It is classification plus precise coordinate tracking.
