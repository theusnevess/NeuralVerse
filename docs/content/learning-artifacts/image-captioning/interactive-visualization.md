# Spatial Attention Heat-map Specification

## Artifact Summary

Specifies an interactive tool for exploring Spatial Attention Heat-map Specification — describes the controls, visual feedback, and conceptual relationships a learner would manipulate to understand Image Captioning.

## Required Contract Fields

### objective

Specify an overlay interface aligning word hover triggers to patch grid cells.

### explanation

This specification outlines an attention heat-map overlay widget. The user clicks words in a generated caption and watches the matching attended grid cells in the input image highlight in orange.
