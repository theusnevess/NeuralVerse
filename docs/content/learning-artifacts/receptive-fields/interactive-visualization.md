# Receptive Field Tracker Spec

## Artifact Summary

This artifact belongs to the Receptive Fields topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify a grid mapping overlay outlining receptive field growth.

### explanation

This specification outlines a receptive field calculator. The user configures kernel sizes and strides for a 3-layer CNN. The tool animates a pyramid highlighting the pixels in the input layer that map to a single activation in the final layer.

## Optional Enrichment Fields

### motivation

Understanding this topic is critical for building stable, industrial-scale Convolutional Neural Networks and transfer learning backbones.
