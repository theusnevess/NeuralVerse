# Agent Evaluation Methodologies

## Artifact Summary

This artifact belongs to the Agent Evaluation Methodologies topic and serves as a Explanatory Text.

## Required Contract Fields

### objective

Explain evaluation dimensions for AI agents: planning quality, tool use accuracy, context retrieval, multi-step execution reliability, and robustness.

### explanation

Agent evaluation extends beyond traditional LLM benchmarks by assessing how well an agent plans, uses tools, retrieves context, executes multi-step tasks, and handles edge cases. Planning quality measures whether the agent's sequence of actions is correct, complete, and efficient for a given goal. Tool use accuracy evaluates whether the agent selects the correct tool and formats parameters properly. Context retrieval checks whether the agent gathers the necessary information before acting. Multi-step execution reliability tracks task completion rate, steps to completion, and recovery from errors. Robustness tests the agent's ability to handle adversarial inputs, ambiguous instructions, and unexpected edge cases without failure.

## Optional Enrichment Fields
