# The Robot Chef Competition

## Artifact Summary

Uses analogy and mental models to build intuition about The Robot Chef Competition — maps familiar concepts to the technical mechanics of Agent Evaluation Methodologies, making abstract ideas concrete.

## Required Contract Fields

### objective

Provide an analogy linking agent evaluation dimensions to a familiar competitive scenario.

### visual focus

Robot chefs compete in a cooking competition judged across four categories that mirror agent evaluation dimensions: planning (following a recipe sequence), tool use (selecting the correct utensil for each step), multi-step execution (cooking multiple dishes without burning anything), and robustness (handling missing or spoiled ingredients by adapting the recipe on the fly).

### interpretation guidance

Each judging category maps directly to an agent evaluation dimension. Recipe planning mirrors planning quality — does the agent choose the right steps in the right order? Utensil selection mirrors tool use accuracy — does the agent pick the correct tool with proper parameters? Cooking without burning mirrors multi-step execution reliability — does the agent complete the entire task without errors? Adapting to missing ingredients mirrors robustness — does the agent recover gracefully when things go wrong?

## Optional Enrichment Fields

Understanding Agent Evaluation Methodologies is critical for building reliable production agents, debugging agent failures, and comparing agent architectures.
