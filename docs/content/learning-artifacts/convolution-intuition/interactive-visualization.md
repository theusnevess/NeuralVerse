# 2D Convolution Animator Spec

## Artifact Summary

This artifact belongs to the Convolution Intuition topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive cell multiplier grid animation.

### explanation

This specification outlines a 2D convolution animator. The user slides a 3 x 3 kernel over a 5 x 5 grid. The tool displays the element-wise multiplications, highlights their sum, and animates the output grid filling up cell-by-cell.
