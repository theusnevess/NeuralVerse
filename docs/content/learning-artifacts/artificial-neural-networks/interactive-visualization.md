# Topology Builder Spec

## Artifact Summary

This artifact belongs to the Artificial Neural Networks topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive network layer constructor.

### explanation

This specification describes a neural network topology builder. The user adds layers, adjusts the number of neurons per layer, and clicks connections to view the weight coefficients in real-time as lines of varying thickness.
