# Neuron Sum Calculation

## Artifact Summary

This artifact belongs to the Artificial Neural Networks topic and serves as a Exercise.

## Required Contract Fields

### objective

Calculate a neuron's pre-activation value manually.

### learner task

A single neuron receives three input values: $x_1 = 0.5$, $x_2 = -1.0$, and $x_3 = 2.0$. The corresponding weights are $w_1 = 0.8$, $w_2 = 0.5$, and $w_3 = -0.3$. The bias is $b = 0.1$. Calculate the pre-activation value $z$.

### expected learner output

$z = (x_1 * w_1) + (x_2 * w_2) + (x_3 * w_3) + b = (0.5 * 0.8) + (-1.0 * 0.5) + (2.0 * -0.3) + 0.1 = 0.4 - 0.5 - 0.6 + 0.1 = -0.6$. The pre-activation value is -0.6.
