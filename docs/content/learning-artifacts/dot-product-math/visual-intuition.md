# Geometric Projection as Dot Product

## Artifact Summary

This artifact belongs to the Dot Product topic and serves as a Visual Intuition.

## Required Contract Fields

### objective

Develop spatial intuition for vectors projecting shadows onto each other.

### explanation

Imagine a flashlight shining directly down on a vector A, casting a shadow onto vector B. The length of that shadow multiplied by the length of B is the dot product. If B is pointing in the same direction, the shadow is long. If A is perpendicular, the shadow is a dot (length 0). This shadow is the projection.
