# Identifying Search Relevance Features

## Artifact Summary

This artifact belongs to the Supervised Learning topic and serves as a Exercise.

## Required Contract Fields

### objective

Analyze similarity search scenarios to classify model variables and tasks.

### learner task

You want to train a model to predict the semantic similarity score (between 0.0 and 1.0) of query-document pairs. Identify the input features, the target labels, and state whether this is a classification or regression task.

### expected learner output

The input features are the query text embedding and the document text embedding. The target labels are the ground-truth human-annotated similarity scores. This is a regression task because the similarity score is a continuous numerical value between 0.0 and 1.0.

This practice does not assign a score and does not certify mastery.
