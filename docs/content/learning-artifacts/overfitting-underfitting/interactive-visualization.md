# Polynomial Curve Fitting Spec

## Artifact Summary

This artifact belongs to the Overfitting and Underfitting topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive curve fitting playground displaying training vs. validation loss graphs.

### explanation

This specification describes a polynomial curve fitting explorer. The user adjusts model complexity (degree of polynomial 1 to 9) to fit noisy points. The tool displays the training and validation error curves, highlighting the zone of underfitting, optimal fit, and overfitting.
