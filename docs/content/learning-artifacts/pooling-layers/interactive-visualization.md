# Grid Downsampling Inspector Spec

## Artifact Summary

This artifact belongs to the Pooling Layers topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive block pooler showing max/avg outputs.

### explanation

This specification describes a pooling operation inspector. The user enters a $4 \times 4$ grid of numbers and clicks a slider to toggle between Max Pooling and Average Pooling ($2 \times 2$ window, stride 2) to watch the downsampled output calculate dynamically.

## Optional Enrichment Fields
