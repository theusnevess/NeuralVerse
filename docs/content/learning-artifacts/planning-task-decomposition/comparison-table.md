# Planning Strategies Compared

## Artifact Summary

This artifact belongs to the Planning and Task Decomposition topic and serves as a Comparison Table.

## Required Contract Fields

### objective

Contrast CoT, ReAct, and pre-planned sub-goal trees.

### explanation

| Planning Method | Key Mechanism | Best Suited For | Primary Limitation |
|---|---|---|---|
| Chain-of-Thought (CoT) | Inline sequential reasoning | Math and logic tasks | No external environment actions |
| ReAct (Reason + Act) | Alternating thought, action, observation | Web search, tool calling | Can get stuck in repetitive error loops |
| Task Decomposition | Pre-planned sub-goal trees | Long-running multi-step projects | Less adaptable to unexpected changes |

## Optional Enrichment Fields
