# The Rare Disease Tester Paradox

## Artifact Summary

This artifact belongs to the Bayes' Theorem topic and serves as a Visual Intuition.

## Required Contract Fields

### objective

Build intuition on how priors balance likelihood tests.

### explanation

Imagine a clinic where 1% of patients have a rare disease. A test for it is 99% accurate. If a patient tests positive, you might think they are 99% likely to have it. But because the disease is so rare, most positive tests are false alarms. Bayes' Theorem acts as a scale that balances the low prior rate against the test accuracy, calculating that the actual chance is only 50%.
