# Bayesian Grid Simulator Spec

## Artifact Summary

Specifies an interactive tool for exploring Bayesian Grid Simulator Spec — describes the controls, visual feedback, and conceptual relationships a learner would manipulate to understand Bayes' Theorem.

## Required Contract Fields

### objective

Specify an interactive dot grid visualising positive test groups.

### explanation

This specification outlines a Bayesian probability grid. The user sets the prior rate and test accuracy rates. The tool visualizes patients as dots on a grid, highlighting true positives, false positives, and calculates the posterior probability visually.
