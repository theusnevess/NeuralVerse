# Volumetric Shadows as Projections

## Artifact Summary

Uses analogy and mental models to build intuition about Volumetric Shadows as Projections — maps familiar concepts to the technical mechanics of Dimensionality Reduction, making abstract ideas concrete.

## Required Contract Fields

### objective

Develop visual intuition for PCA and t-SNE projection maps.

### explanation

Imagine a 3D wire sculpture of a bird. If you shine a light on it, its shadow on the wall is a 2D projection. If you rotate the sculpture, the shadow changes. PCA finds the angle that spreads out the shadow as much as possible, keeping the bird's structure visible. t-SNE/UMAP are like squishing the bird flat while keeping nearby wires close together.
