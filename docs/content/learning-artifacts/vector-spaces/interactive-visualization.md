# Vector Spaces Interactive Exploration Spec

## Artifact Summary

This artifact belongs to the Vector Spaces topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive tool to let learners manipulate dimension values and observe vector changes.

### explanation

This specification describes an interactive 3D plotter. The interface contains sliders for three dimensions: Sweetness, Acidity, and Ripeness. Learners can create custom fruit vectors and plot them in real-time. The tool visualizes the coordinate axes, basis vectors, and the resulting vector arrow pointing from the origin (0,0,0) to the item's coordinates. As the learner modifies the sliders, the vector dynamically stretches, rotates, and updates its numeric coordinates on screen.
