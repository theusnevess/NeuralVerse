# Reasoning About Vector Spaces

## Artifact Summary

This artifact belongs to the Vector Spaces topic and serves as a Exercise.

## Required Contract Fields

### objective

Practice identifying coordinate features and defining vector spaces for specific datasets.

### learner task

Given a list of books, identify a 3-dimensional feature set that could represent them as vectors (e.g., Action level, Romantic theme, Page count). Then, map three books to approximate coordinates in your space and explain why their relative positions match your expectations.

### expected learner output

The learner should define a 3D coordinate space representing Action, Romance, and Page count. Book A (Sci-Fi Action) -> (9, 2, 400). Book B (Romance Novel) -> (1, 9, 300). Book C (Action-Romance crossover) -> (7, 6, 350). The relative coordinates should show logical spatial proximity according to the feature definitions.

This practice does not assign a score and does not certify mastery.
