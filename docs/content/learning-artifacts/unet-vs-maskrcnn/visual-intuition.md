# Grid Maps vs. Private Fences

## Artifact Summary

This artifact belongs to the U-Net vs Mask R-CNN (Conceptual Comparison) topic and serves as a Visual Intuition.

## Required Contract Fields

### objective

Provide an analogy based on map borders vs fenced private yards.

### explanation

U-Net is like a mapmaker who draws borders for forests and lakes directly onto a grid. Mask R-CNN is like a land surveyor who first places fences around each private house (bounding boxes) and then draws the shape of the building inside each fenced yard.
