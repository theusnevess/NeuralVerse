# Anchor Template Overlay Spec

## Artifact Summary

This artifact belongs to the Anchor-Based vs Anchor-Free Detection topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify a grid selector showing template anchors vs anchor-free direction maps.

### explanation

This specification describes an anchor layout comparison tool. The user toggles between 'Anchor-based Grid' (rendering 3 clusters of overlapping colored outlines at each cell) and 'Anchor-free Grid' (rendering center dots and direction arrows).
