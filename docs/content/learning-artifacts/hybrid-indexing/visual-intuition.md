# Searching the Specialized Doctor Directory

## Artifact Summary

This artifact belongs to the Hybrid Indexing Strategies topic and serves as a Visual Intuition.

## Required Contract Fields

### objective

Provide an analogy combining attribute filters, keyword search, and description matching.

### explanation

Imagine searching for a doctor. You can look at a directory list filtering by specialty 'Cardiology' (metadata), search for the exact name 'Dr. Smith' (lexical search), or look for 'heart specialist' (semantic vector search). Combining all three methods guarantees you find the doctor, regardless of whether you know their name or just what they do.
