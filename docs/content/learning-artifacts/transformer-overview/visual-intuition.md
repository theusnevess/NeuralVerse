# Sequential Assembly vs. Shared Blueprints

## Artifact Summary

This artifact belongs to the Transformer Architecture Overview topic and serves as a Visual Intuition.

## Required Contract Fields

### objective

Provide an analogy based on assembly lines vs table collaborations.

### explanation

Imagine a factory assembly line where every worker must wait for the person before them to finish before they can proceed (sequential RNN). The Transformer is like replacing the line with a shared table where all workers read the entire blueprint at once, communicating with each other simultaneously to build the product in parallel.

## Optional Enrichment Fields

### motivation

Understanding Transformers is critical for building modern LLMs (GPT-4, Llama), semantic search retrievers, RAG interfaces, and Vision Transformers.
