# Throughput Timeline Spec

## Artifact Summary

This artifact belongs to the Transformer Architecture Overview topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

### explanation

This specification describes a comparative throughput timeline. The user drags a slider to watch a sentence process token-by-token in an RNN vs. all-at-once in a Transformer encoder.
