# Visualizing Attention Curves

## Artifact Summary

This artifact belongs to the Context Window Management topic and serves as a Visual Intuition.

## Required Contract Fields

### objective

Visualize U-shaped attention curves in long prompts.

### explanation

Imagine giving a student a 500-page book and asking them to find a single fact. If the fact is on page 1 or page 500, they find it quickly. If it is on page 250, they might miss it or get distracted by the surrounding text. Keeping the prompt small and placing the key documents at the book's outer edges ensures the student answers correctly.
