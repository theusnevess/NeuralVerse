# Context Layout Interactive Spec

## Artifact Summary

This artifact belongs to the Context Window Management topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive editor showing estimated LLM attention intensity based on document placement.

### explanation

This specification outlines a context layout visualizer. The user arranges document chunks inside a prompt template. The tool highlights the 'Attention Intensity' curve, showing high intensity at the beginning and end, and low intensity in the middle. The user can toggle sorting options to see how layout optimization moves key information to high-attention zones.
