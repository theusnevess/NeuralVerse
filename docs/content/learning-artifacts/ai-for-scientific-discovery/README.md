# AI for Scientific Discovery

## Purpose

This draft artifact set introduces the paradigm of AI for scientific discovery — using machine learning systems to accelerate hypothesis generation, experimental design, simulation, and theory formation across scientific disciplines.

The set helps learners understand how AI transforms the scientific method, where specific techniques (surrogate modeling, inverse design, Bayesian optimization) apply, and what challenges remain open.
