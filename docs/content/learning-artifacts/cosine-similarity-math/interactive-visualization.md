# Cosine Similarity Unit Circle Spec

## Artifact Summary

Specifies an interactive tool for exploring Cosine Similarity Unit Circle Spec — describes the controls, visual feedback, and conceptual relationships a learner would manipulate to understand Cosine Similarity.

## Required Contract Fields

### objective

Specify an interactive unit circle showing angle-only projections.

### explanation

This specification describes a cosine similarity explorer. The user adjusts vector lengths and angles. The tool shows a unit circle, showing how vectors are projected onto the circle (normalization) and calculates the cosine of the angle between them.
