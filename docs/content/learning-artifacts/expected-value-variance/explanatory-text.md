# Expected Value, Variance, and Dispersion

## Artifact Summary

This artifact belongs to the Expected Value and Variance topic and serves as a Explanatory Text.

## Required Contract Fields

### objective

Explain mathematical formulations of expected value, variance, standard deviation, and the bias-variance trade-off.

### explanation

Expected Value (E[X]) represents the long-term average value of a random variable: E[X] = sum(x_i * P(x_i)) for discrete variables. Variance (Var(X)) measures the spread or dispersion of the variable around its expected value: Var(X) = E[(X - E[X])^2]. Standard Deviation is the square root of variance. In AI, expected value is used to calculate average loss, while variance describes model stability. The bias-variance trade-off is a central concept: high bias means underfitting, while high variance means overfitting.
