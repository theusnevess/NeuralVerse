# Common Probability Distributions and Softmax

## Artifact Summary

This artifact belongs to the Probability Distributions topic and serves as a Explanatory Text.

## Required Contract Fields

### objective

Introduce Bernoulli, Normal, Uniform distributions and the softmax activation function.

### explanation

A probability distribution describes how probabilities are distributed over the values of a random variable. Key distributions in AI include: 1. Bernoulli: Models binary outcomes (e.g., yes/no classification, success/failure). 2. Uniform: All outcomes are equally likely (e.g., initial random weights). 3. Normal (Gaussian): Bell-shaped curve centered around a mean, representing natural variations (e.g., sensor noise, distribution of word embedding dimensions). 4. Categorical: Models multi-class probabilities, typically generated in neural networks using the Softmax function.
