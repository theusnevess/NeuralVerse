# Geometric Linear Transformations

## Artifact Summary

Covers Geometric Linear Transformations within the broader topic of Linear Transformations — explains the core ideas, their role in AI systems, and what makes them important for practitioners to understand.

## Required Contract Fields

### objective

Explain matrix multiplication as a geometric transformation of vector spaces.

### explanation

A linear transformation is a mapping between vector spaces that preserves vector addition and scalar multiplication. Mathematically, multiplying a vector x by a matrix A (y = Ax) transforms x to a new position. Geometrically, this transformation can rotate, scale, shear, or project the entire space. In neural networks, linear transformations map inputs to new feature spaces where patterns are easier to classify. A weight matrix acts as a transformation mapping raw input embeddings (like words) into task-specific spaces (like sentiment space).
