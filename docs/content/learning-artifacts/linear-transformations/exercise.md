# Applying Linear Transformations

## Artifact Summary

This artifact belongs to the Linear Transformations topic and serves as a Exercise.

## Required Contract Fields

### objective

Compute vector transformations algebraically and explain the geometric effect.

### learner task

A 2D vector x = [1, 2] is transformed by a matrix A = [[2, 0], [0, 3]]. Calculate the output vector y = Ax. Explain geometrically what this transformation did to the vector space.

### expected learner output

y = [ (2*1 + 0*2), (0*1 + 3*2) ] = [2, 6]. Geometrically, this matrix scaled the vector space by a factor of 2 along the X-axis, and by a factor of 3 along the Y-axis, representing a non-uniform stretch.
