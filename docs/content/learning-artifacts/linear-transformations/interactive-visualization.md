# Linear Grid Transformation Spec

## Artifact Summary

This artifact belongs to the Linear Transformations topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive visual grid mapping matrix indices to visual stretches.

### explanation

This specification describes a linear transformation grid explorer. The user edits elements of a 2x2 transformation matrix. The tool animates how a grid of vectors transforms (rotates, scales, shears) in real-time, showing how base vectors [1,0] and [0,1] map to the columns of the matrix.
