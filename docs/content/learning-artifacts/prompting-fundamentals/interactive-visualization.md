# Prompt Block Builder Spec

## Artifact Summary

This artifact belongs to the Prompting Fundamentals topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive interface to construct and inspect raw prompt payloads.

### explanation

This specification describes a prompt structure builder. The user toggles buttons to assemble a prompt: Instruction + Context + Few-shot Examples + CoT Trigger, watching the raw payload build in a preview pane.
