# Distance Metrics Interactive Spec

## Artifact Summary

This artifact belongs to the Distance Metrics topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive tool where learners manipulate vector coordinates and observe distance metrics.

### explanation

This specification outlines an interactive 2D canvas showing two vector arrows originating from the center. Learners drag the heads of the vector arrows. A sidebar displays the active coordinates, vector magnitudes, Euclidean Distance, Cosine Similarity, and Dot Product. Highlighting colors demonstrate magnitude changes (Euclidean and Dot Product reaction) versus angle changes (Cosine reaction).
