# The Artisan and the Tool Box

## Artifact Summary

This artifact belongs to the Tool Calling and External Actions topic and serves as a Visual Intuition.

## Required Contract Fields

### objective

Provide an analogy based on tools scaling manual hands.

### explanation

An agent is like an artisan. The model itself is the artisan's brain, which knows *how* to build things. The tools (APIs, calculators, databases) are the hammer, saw, and tape measure. The artisan cannot drive a nail with their fingers; they must choose the hammer from their toolbox, hold it correctly (arguments), and use it to strike the nail (API execution).

## Optional Enrichment Fields

### motivation

Understanding AI Agents and Tool Use is critical for building autonomous software assistants, function callers, memory-backed bots, and self-correcting coders.
