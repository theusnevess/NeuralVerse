# Static LLMs vs. AI Agents

## Artifact Summary

This artifact belongs to the Agentic AI Fundamentals topic and serves as a Comparison Table.

## Required Contract Fields

### objective

Contrast lifetimes, interactions, and optimization targets.

### explanation

| Metric / Feature | Static LLM | AI Agent |
|---|---|---|
| Execution Lifetime | Single-turn (one forward pass, then halts) | Multi-turn loops (continues until goal met) |
| Environment Interaction | None (isolated text continuation) | High (executes actions and reads environment state) |
| Core Logic focus | Next-token probability optimization | Goal alignment and dynamic tool orchestration |

## Optional Enrichment Fields

Understanding AI Agents and Tool Use is critical for building autonomous software assistants, function callers, memory-backed bots, and self-correcting coders.
