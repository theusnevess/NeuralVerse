# Interpolation Simulator Spec

## Artifact Summary

This artifact belongs to the Image Resolution, Sampling, and Resizing topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive resizing board comparing nearest neighbor and bilinear interpolations.

### explanation

This specification describes an interpolation simulator. The user scales a small 8 x 8 icon up to 64 x 64 and toggles between Nearest Neighbor and Bilinear modes to observe the pixel grid calculations and boundary smoothing differences.
