# Source-Response Citation Mapper Spec

## Artifact Summary

Specifies an interactive tool for exploring Source-Response Citation Mapper Spec — describes the controls, visual feedback, and conceptual relationships a learner would manipulate to understand Knowledge Grounding and Attribution.

## Required Contract Fields

### objective

Specify an interface aligning response sentences to original document files.

### explanation

This specification describes a citation correlation map. The user highlights sentences in the LLM's generated response, watching dotted lines trace back to highlight the exact matching sentences in the source document window.
