# The Open-Book History Exam

## Artifact Summary

This artifact belongs to the Knowledge Grounding and Attribution topic and serves as a Visual Intuition.

## Required Contract Fields

### objective

Provide an analogy representing strict document limits and mandated citations.

### explanation

Imagine an open-book history exam. The teacher gives the student a short text about ancient Rome and instructs them: 'You must answer the questions using only this sheet. If you write something that isn't on this sheet, even if it is historically true, you get zero points. Furthermore, you must write the line number where you found your answer next to each sentence.'
