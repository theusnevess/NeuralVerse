# The Study, Practice, and Exam Analogy

## Artifact Summary

Uses analogy and mental models to build intuition about The Study, Practice, and Exam Analogy — maps familiar concepts to the technical mechanics of Train / Validation / Test Split, making abstract ideas concrete.

## Required Contract Fields

### objective

Provide an analogy for data partitions based on exam preparations.

### explanation

Imagine preparing for a final exam. The training set is the textbook and practice problems you study. The validation set is the practice test you take to check your progress and adjust your study habits. The test set is the actual final exam, which you've never seen before. If you look at the final exam questions while studying, that is data leakage.
