# Evaluating Embedding Model Selection

## Artifact Summary

This artifact belongs to the Embedding Models topic and serves as a Exercise.

## Required Contract Fields

### objective

Analyze project search requirements and recommend dense or sparse model types.

### learner task

You need to build a search system for medical patents where exact chemical names must match precisely, but general medical concepts must also match semantically. Which embedding model type or hybrid approach would you choose and why?

### expected learner output

The learner should propose a hybrid search approach (combining sparse representation for exact matches like chemical names and dense representation for general semantic concepts), explaining how each model meets a specific part of the requirement.

This practice does not assign a score and does not certify mastery.
