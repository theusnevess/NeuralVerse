# K-Means Cluster Explorer Spec

## Artifact Summary

This artifact belongs to the Unsupervised Learning topic and serves as a Interactive Visualization.

## Required Contract Fields

### objective

Specify an interactive K-Means visualizer displaying cluster centroid recalculations.

### explanation

This specification outlines a K-Means clustering explorer. The user adjusts the number of clusters (K) and generates a point cloud. The tool animates the cluster centroids moving and points updating their group colors until convergence.
