## Artifact Summary

This artifact belongs to the Unsupervised Learning topic and serves as a Comparison Table.

## Required Contract Fields

### objective

Compare supervised and unsupervised data structures, objectives, and algorithms.

### explanation

| Paradigm | Dataset Structure | Core Objective | Typical Algorithms |
|---|---|---|---|
| Supervised | Input Features + Ground-truth Labels | Predict labels for unseen inputs | Dense Layers, SVM, Decision Trees |
| Unsupervised | Input Features only | Discover hidden patterns/groups | K-Means, PCA, UMAP, DBScan |
