# Agent Evaluation Methodologies — Lesson Composition

## 1. Purpose

This lesson orchestrates reusable Learning Artifacts into a coherent learning experience about Agent Evaluation Methodologies.

The lesson is not a monolithic instructional document. It references independent artifacts, assigns each artifact a pedagogical role, and defines a recommended learning flow.

## 2. Learning Goal

After completing this lesson flow, the learner should understand the key dimensions of agent evaluation and be able to reason about planning quality, tool use accuracy, context retrieval, multi-step execution reliability, and robustness.

## 3. Covered Concepts

*   Core evaluation dimensions for AI agents;
*   Practical trade-offs in measuring agent performance;
*   Visual and spatial models representing evaluation relationships.

## 4. Artifact Composition

### 4.1 Explanatory Text

Artifact: `artifact-agent-evaluation-explanatory-text`
Role: Introduces the core vocabulary, defining evaluation dimensions and terminology.

### 4.2 Visual Intuition

Artifact: `artifact-agent-evaluation-visual-intuition`
Role: Provides a cooking competition analogy to build a strong mental model.

### 4.3 Interactive Visualization

Artifact: `artifact-agent-evaluation-interactive-visualization`
Role: Outlines an interactive spec where agent traces can be inspected step by step.

### 4.4 Exercise

Artifact: `artifact-agent-evaluation-exercise`
Role: Practice evaluating agent execution traces to apply the knowledge.

### 4.5 Comparison Table

Artifact: `artifact-agent-evaluation-comparison-table`
Role: Consolidates the lesson with a structural comparative reference across dimensions.

## 5. Composition Rationale

### 5.1 Recommended Learning Flow Map

```text
Recommended Learning Flow

Explanatory Text
        ↓
Visual Intuition
        ↓
Interactive Visualization
        ↓
Exercise
        ↓
Comparison Table
```

### 5.2 Rationale Details

The sequence begins with explanation to establish vocabulary. Visual intuition follows to create a relatable mental model. The interactive specification provides exploration space for trace analysis, preparing the learner for the exercise. The comparison table consolidates differences as a reference.
