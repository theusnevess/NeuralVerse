# Neurosymbolic AI — Lesson Composition

## 1. Purpose

This lesson orchestrates reusable Learning Artifacts into a coherent learning experience about Neurosymbolic AI — the integration of neural learning with symbolic reasoning.

The lesson is not a monolithic instructional document. It references independent artifacts, assigns each artifact a pedagogical role, and defines a recommended learning flow.

## 2. Learning Goal

After completing this lesson flow, the learner should understand the neurosymbolic paradigm, its key integration patterns, major architectures (LNNs, program synthesis, neural theorem proving, GNNs for reasoning), and the open challenges at the intersection of neural and symbolic AI.

## 3. Covered Concepts

*   The neurosymbolic paradigm — combining connectionist and symbolic traditions;
*   Key integration patterns: symbolic neural, neural-symbolic, and hybrid architectures;
*   Differentiable programming, Logical Neural Networks, program synthesis, and neural theorem proving;
*   Graph neural networks for relational reasoning and knowledge graph integration;
*   The System 1 / System 2 framing and its relevance to neurosymbolic design;
*   Open challenges: differentiability, brittleness, scalability, and the grounding problem.

## 4. Artifact Composition

### 4.1 Explanatory Text

Artifact: `artifact-neurosymbolic-ai-explanatory-text`
Role: Introduces the core vocabulary, defining the neurosymbolic paradigm, integration patterns, key architectures, and open challenges.

### 4.2 Visual Intuition

Artifact: `artifact-neurosymbolic-ai-visual-intuition`
Role: Provides the "Architect and the Sculptor" analogy to build a strong mental model of how symbolic reasoning and neural learning complement each other.

### 4.3 Interactive Visualization

Artifact: `artifact-neurosymbolic-ai-interactive-visualization`
Role: Outlines a "Neurosymbolic Integration Explorer" spec where users toggle between neural-only, symbolic-only, and hybrid modes to observe differences in accuracy, sample efficiency, and out-of-distribution generalization.

### 4.4 Exercise

Artifact: `artifact-neurosymbolic-ai-exercise`
Role: Practice designing neurosymbolic architectures across three contexts — theorem proving, visual question answering, and scientific hypothesis generation — focusing on the neural-symbolic interface and grounding problem.

### 4.5 Comparison Table

Artifact: `artifact-neurosymbolic-ai-comparison-table`
Role: Consolidates the lesson with a structural reference comparing Pure Neural, Pure Symbolic, Logical Neural Networks, Neural Program Synthesis, Differentiable Reasoning, and Graph-based Reasoning.

## 5. Composition Rationale

### 5.1 Recommended Learning Flow Map

```text
Recommended Learning Flow

Explanatory Text
        ↓
Visual Intuition
        ↓
Interactive Visualization
        ↓
Exercise
        ↓
Comparison Table
```

### 5.2 Rationale Details

The sequence begins with explanation to establish the neurosymbolic vocabulary and the complementary limitations of pure neural and pure symbolic approaches. Visual intuition follows to create an accessible mental model (architect and sculptor). The interactive specification provides an environment to explore trade-offs between modes, preparing the learner for the design exercise. The comparison table consolidates the different neurosymbolic approaches as a quick-reference summary.
