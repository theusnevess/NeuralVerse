# AI for Scientific Discovery

## Lesson Purpose

This draft lesson composition demonstrates how reusable Learning Artifacts can be orchestrated into a coherent learning experience about AI for scientific discovery.

The lesson introduces the paradigm of embedding AI systems into the scientific discovery pipeline — hypothesis generation, experiment design, simulation, analysis, and theory refinement — across multiple scientific disciplines.

## Participating Artifacts

* `artifact-ai-for-scientific-discovery-explanatory-text`
* `artifact-ai-for-scientific-discovery-visual-intuition`
* `artifact-ai-for-scientific-discovery-interactive-visualization`
* `artifact-ai-for-scientific-discovery-exercise`

## Architectural Role

This lesson validates the NV-800 principle that a lesson is an orchestrated learning experience, not a monolithic content file.

It references independently governed Learning Artifacts and preserves their reuse potential.

## Relationship With NV-800-M5 and NV-800-M7

NV-800-M5 defines lesson orchestration.

NV-800-M7 defines Learning Artifact taxonomy, contracts, lifecycle, reuse, metadata, dependencies, and quality governance.

This draft composition uses both foundations without introducing assessment logic, Competency Evidence, runtime composition, UI, backend services, or dependency enforcement.
