# LLM Evaluation Fundamentals

*   **Module ID:** `module-llm-evaluation-fundamentals`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to the core evaluation paradigms for LLMs, including automatic metric computation and limitations, human annotation design and agreement measurement, and benchmark selection and result interpretation.

## Included Lessons

*   [Automatic Evaluation Metrics](../../lessons/automatic-evaluation-metrics/) (`lesson-automatic-evaluation-metrics`)
*   [Human Evaluation of LLMs](../../lessons/human-evaluation/) (`lesson-human-evaluation`)
*   [Task-Specific Benchmarking](../../lessons/task-specific-benchmarking/) (`lesson-task-specific-benchmarking`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as evaluation data curation, bias and fairness metrics, or cost-aware evaluation frameworks.
