# Retrieval Pipeline Foundations

*   **Module ID:** `module-retrieval-pipeline-foundations`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to the first stages of modern retrieval pipelines: splitting unstructured documents, selecting suitable embedding models, and preprocessing raw user queries.

## Included Lessons

*   [Chunking Strategies](../../lessons/chunking-strategies/) (`lesson-chunking-strategies`)
*   [Embedding Models](../../lessons/embedding-models/) (`lesson-embedding-models`)
*   [Query Expansion and Reformulation](../../lessons/query-expansion-reformulation/) (`lesson-query-expansion-reformulation`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as advanced parser systems, metadata schema extraction, dynamic sliding window chunking, or fine-tuning local embedding models.
