# Detection Fundamentals

*   **Module ID:** `module-detection-fundamentals`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to the fundamentals of object detection, including spatial localization vs. classification heads, absolute and normalized bounding box coordinate representations, and overlap calculation metrics (Intersection over Union).

## Included Lessons

*   [Object Detection Fundamentals](../../lessons/object-detection-fundamentals/) (`lesson-object-detection-fundamentals`)
*   [Bounding Boxes and Coordinate Systems](../../lessons/bounding-boxes-coordinates/) (`lesson-bounding-boxes-coordinates`)
*   [Intersection over Union (IoU)](../../lessons/intersection-over-union/) (`lesson-intersection-over-union`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as generalized IoU metrics (GIoU, DIoU, CIoU), multi-task loss weight optimizations, or custom anchor labeling conventions.
