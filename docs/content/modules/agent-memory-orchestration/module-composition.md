# Agent Memory & Orchestration — Module Composition

## 1. Purpose

This module organizes lessons related to agent memory and orchestration patterns, focusing on the differences between active context short-term memory and long-term vector database storage, critique-based self-correction loops for error recovery, and collaborative multi-agent patterns using specialized personas and message routing.

It provides an organizational boundary for context windows, error logs, and multi-persona networks without duplicating any instructional content.

## 2. Module Learning Aim

Introduce learners to agent memory and orchestration patterns, focusing on the differences between active context short-term memory and long-term vector database storage, critique-based self-correction loops for error recovery, and collaborative multi-agent patterns using specialized personas and message routing.

This module aims to connect active conversation history to saved summaries, compiler messages to corrected generations, and role tasks to communication nodes, without claiming or certifying competency mastery.
