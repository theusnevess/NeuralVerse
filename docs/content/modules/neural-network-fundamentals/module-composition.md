# Neural Network Fundamentals — Module Composition

## 1. Purpose

This module organizes foundational lessons related to deep neural network structure, propagation, and activations.

It provides an organizational boundary for node equations, forward matrix transitions, and non-linear outputs without duplicating any instructional content.

## 2. Module Learning Aim

Introduce learners to the architectural fundamentals of deep artificial neural networks, including layer typologies, forward propagation flows, and activation functions.

This module aims to connect architectures to representation learning, inference runs, and non-linear thresholds, without claiming or certifying competency mastery.

## 3. Included Lessons

### 3.1 Artificial Neural Networks

*   **Lesson ID:** `lesson-artificial-neural-networks`
*   **Location:** `docs/content/lessons/artificial-neural-networks/lesson-composition.md`
*   **Pedagogical Role:** Teaches biological analogies, MLP hidden layers, weight/bias parameters, and representation learning.
*   **Relationship to Module Aim:** Fulfills the network architecture and neuron mapping requirement of the learning aim.

### 3.2 Forward Propagation

*   **Lesson ID:** `lesson-forward-propagation`
*   **Location:** `docs/content/lessons/forward-propagation/lesson-composition.md`
*   **Pedagogical Role:** Focuses on pre-activation linear sums, matrix multiplications, and post-activation output transitions.
*   **Relationship to Learning Path Aim:** Fulfills the forward inference vector flow requirement of the learning aim.

### 3.3 Activation Functions

*   **Lesson ID:** `lesson-activation-functions`
*   **Location:** `docs/content/lessons/activation-functions/lesson-composition.md`
*   **Pedagogical Role:** Compares Sigmoid classification boundaries, ReLU sparsity, Softmax category probabilities, and vanishing gradients.
*   **Relationship to Learning Path Aim:** Fulfills the non-linear mappings and function saturation requirement of the learning aim.

This module composition does not duplicate any of the instructional content or text from the lesson compositions themselves.

## 4. Module Composition Flow

The module structures lessons in the following sequence:

1.  **Artificial Neural Networks** (`lesson-artificial-neural-networks`)
2.  **Forward Propagation** (`lesson-forward-propagation`)
3.  **Activation Functions** (`lesson-activation-functions`)
