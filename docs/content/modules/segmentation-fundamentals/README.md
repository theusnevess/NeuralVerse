# Segmentation Fundamentals

*   **Module ID:** `module-segmentation-fundamentals`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to the fundamentals of image segmentation, including semantic category grouping, pixel-wise classification logs, output logit channel Softmax activations, and integer label map annotations.

## Included Lessons

*   [Semantic Segmentation Fundamentals](../../lessons/semantic-segmentation-fundamentals/) (`lesson-semantic-segmentation-fundamentals`)
*   [Pixel-wise Classification](../../lessons/pixel-wise-classification/) (`lesson-pixel-wise-classification`)
*   [Segmentation Masks and Label Maps](../../lessons/segmentation-masks-labels/) (`lesson-segmentation-masks-labels`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as boundary loss functions, panoptic segmentation pipelines, or multi-scale feature fusion layers.
