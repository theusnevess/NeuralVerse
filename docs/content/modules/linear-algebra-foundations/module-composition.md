# Linear Algebra Foundations — Module Composition

## 1. Purpose

This module organizes foundational lessons related to numerical arrays, dot product mappings, and parallel row-column multiplications.

It provides an organizational boundary for scalars, vectors, matrices, tensors, inner products, and matrix algebra without duplicating any instructional content.

## 2. Module Learning Aim

Introduce learners to the basic structures and operations of linear algebra underpinning modern artificial intelligence, including scalars, vectors, matrices, tensors, dot products, and matrix multiplication.

This module aims to connect algebraic operations to practical neural computing and vector layouts, without claiming or certifying competency mastery.

## 3. Included Lessons

### 3.1 Scalars, Vectors, Matrices, and Tensors

*   **Lesson ID:** `lesson-scalars-vectors-matrices-tensors`
*   **Location:** `docs/content/lessons/scalars-vectors-matrices-tensors/lesson-composition.md`
*   **Pedagogical Role:** Details array rank, nested dimensions, shape tuples, and color channel tensors.
*   **Relationship to Module Aim:** Fulfills the multi-dimensional array representation requirement of the learning aim.

### 3.2 Dot Product

*   **Lesson ID:** `lesson-dot-product-math`
*   **Location:** `docs/content/lessons/dot-product-math/lesson-composition.md`
*   **Pedagogical Role:** Explains algebraic inner products, geometric vector projection, and sign-angle alignment mapping.
*   **Relationship to Module Aim:** Fulfills the vector projection and alignment operation requirement of the learning aim.

### 3.3 Matrix Multiplication

*   **Lesson ID:** `lesson-matrix-multiplication`
*   **Location:** `docs/content/lessons/matrix-multiplication/lesson-composition.md`
*   **Pedagogical Role:** Teaches dimension checking, batch dot products, and row-column transformation steps in neural layers.
*   **Relationship to Module Aim:** Fulfills the batch calculation and matrix product requirement of the learning aim.

This module composition does not duplicate any of the instructional content or text from the lesson compositions themselves.
