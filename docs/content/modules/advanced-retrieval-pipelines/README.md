# Advanced Retrieval Pipelines

*   **Module ID:** `module-advanced-retrieval-pipelines`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to advanced query and context engineering within retrieval pipelines, focusing on query intent-based routing switches, Reciprocal Rank Fusion (RRF) rank-combining math, and multi-index hybrid search architectures.

## Included Lessons

*   [Query Routing and Intent Detection](../../lessons/query-routing/) (`lesson-query-routing`)
*   [Context Fusion and Aggregation](../../lessons/context-fusion/) (`lesson-context-fusion`)
*   [Hybrid Indexing Strategies](../../lessons/hybrid-indexing/) (`lesson-hybrid-indexing`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as sub-query translation engines, graph database indices, or metadata caching layers.
