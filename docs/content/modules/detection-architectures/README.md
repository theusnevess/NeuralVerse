# Detection Architectures

*   **Module ID:** `module-detection-architectures`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to the architectural paradigms of object detection, including anchor-based templates vs. anchor-free center coordinate regressions, Non-Maximum Suppression overlap suppressions, and one-stage vs. two-stage candidate proposal pipelines.

## Included Lessons

*   [Anchor-Based vs Anchor-Free Detection](../../lessons/anchor-based-vs-free/) (`lesson-anchor-based-vs-free`)
*   [Non-Maximum Suppression (NMS)](../../lessons/non-maximum-suppression/) (`lesson-non-maximum-suppression`)
*   [One-Stage vs Two-Stage Detectors](../../lessons/one-stage-vs-two-stage/) (`lesson-one-stage-vs-two-stage`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as transformer-based detection heads (DETR, RT-DETR), Feature Pyramid Networks (FPN), or Soft-NMS algorithms.
