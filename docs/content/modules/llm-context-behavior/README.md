# LLM Context & Behavior

*   **Module ID:** `module-llm-context-behavior`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to the behavioral properties of LLMs during inference, including context window constraints, Key-Value (KV) cache sizing, In-Context Learning (ICL) activation theories, and the causes and mitigation strategies for hallucinations.

## Included Lessons

*   [Context Windows and Long Context](../../lessons/context-windows-long/) (`lesson-context-windows-long`)
*   [In-Context Learning](../../lessons/in-context-learning/) (`lesson-in-context-learning`)
*   [Hallucinations and Reliability](../../lessons/hallucinations-reliability/) (`lesson-hallucinations-reliability`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as RoPE (Rotary Position Embeddings) scaling methods, self-correction decoding paths, and retrieval-augmented grounding performance checks.
