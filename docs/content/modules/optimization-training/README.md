# Optimization and Training

*   **Module ID:** `module-optimization-training`

## Module Aim

Introduce learners to deep learning optimization, including backpropagation algorithms, SGD and Adam optimizers, and training schedules (epochs, batches, and learning rates).

*   [Backpropagation](../../lessons/backpropagation/) (`lesson-backpropagation`)
*   [Gradient Descent and Optimization](../../lessons/gradient-descent-optimization/) (`lesson-gradient-descent-optimization`)
*   [Epochs, Batches, and Learning Rate](../../lessons/epochs-batches-learning-rate/) (`lesson-epochs-batches-learning-rate`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

Future lessons may extend this module with topics such as weight initialization strategies, learning rate warmups, second-order optimizers (L-BFGS), or distributed training synchronization.
