# Sequence Representation

*   **Module ID:** `module-sequence-representation`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to sequence representations in Transformers, including absolute/relative positional encodings, sinusoidal wave addition layers, encoder vs. decoder causal mask routing, and subword tokenization dictionary lookups.

## Included Lessons

*   [Positional Encoding](../../lessons/positional-encoding/) (`lesson-positional-encoding`)
*   [Encoder vs Decoder Architectures](../../lessons/encoder-vs-decoder/) (`lesson-encoder-vs-decoder`)
*   [Tokenization and Token Representations](../../lessons/tokenization-representations/) (`lesson-tokenization-representations`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as RoPE (Rotary Position Embeddings), Byte-level tokenizers, or vocab size optimizations for multilingual models.
