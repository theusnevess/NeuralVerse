# LLM Core Concepts

*   **Module ID:** `module-llm-core`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to the architectural core of Large Language Models (LLMs), including self-supervised pre-training, Kaplan and Chinchilla scaling laws, token-by-token autoregressive generation loops, temperature/top-k/top-p decoding parameter controls, and prompt shaping mechanics.

*   [Large Language Models Overview](../../lessons/llm-overview/) (`lesson-llm-overview`)
*   [Autoregressive Generation](../../lessons/autoregressive-generation/) (`lesson-autoregressive-generation`)
*   [Prompting Fundamentals](../../lessons/prompting-fundamentals/) (`lesson-prompting-fundamentals`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as pre-training datasets token filtering, compute-optimal training dynamics, and basic reinforcement learning alignment objectives.
