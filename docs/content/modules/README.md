# Modules

This directory contains draft NeuralVerse module compositions.

Modules organize Lessons into coherent instructional units. They represent higher-level structuring within a learning experience, but they are not learning paths themselves.

## Key Rules

*   **No Mastery Certification:** Modules do not certify mastery.
*   **No Competency Evidence:** Modules do not generate Competency Evidence.
*   **No Content Duplication:** Modules do not duplicate the actual learning content or text from lessons or learning artifacts.
