# Vector Retrieval Architectures

*   **Module ID:** `module-vector-retrieval-architectures`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to vector storage engines, indexing strategies, metadata filtering, and Retrieval-Augmented Generation (RAG) loops as modern AI retrieval systems.

## Included Lessons

*   [Vector Databases](../../lessons/vector-databases/) (`lesson-vector-databases`)
*   [RAG Foundations](../../lessons/rag-foundations/) (`lesson-rag-foundations`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as hybrid search, dense-sparse retrieval, multi-modal embeddings, agentic RAG, or query translation and routing.
