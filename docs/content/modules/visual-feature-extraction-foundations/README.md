# Visual Feature Extraction Foundations

*   **Module ID:** `module-visual-feature-extraction-foundations`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to spatial feature extraction in computer vision, including 2D convolutions (kernels, stride, padding), feature maps (gradients, blurring), and the paradigm shift from classical hand-crafted descriptors to deep representation learning.

## Included Lessons

*   [Convolution Intuition](../../lessons/convolution-intuition/) (`lesson-convolution-intuition`)
*   [Feature Maps and Filters](../../lessons/feature-maps-filters/) (`lesson-feature-maps-filters`)
*   [Classical Computer Vision vs Deep Learning Vision](../../lessons/classical-vs-deep-vision/) (`lesson-classical-vs-deep-vision`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as pooling operations (max pooling, average pooling), dilated convolutions, spatial pyramid pooling, or scale-invariant feature transforms.
