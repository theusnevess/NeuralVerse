# Statistical Reasoning for AI

*   **Module ID:** `module-statistical-reasoning-ai`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to essential statistical reasoning principles in AI, including expected values, variance metrics, bias-variance tradeoffs, representative sampling, data drift, and correlation vs. causation.

## Included Lessons

*   [Expected Value and Variance](../../lessons/expected-value-variance/) (`lesson-expected-value-variance`)
*   [Sampling and Sampling Bias](../../lessons/sampling-bias/) (`lesson-sampling-bias`)
*   [Correlation vs. Causation](../../lessons/correlation-causation/) (`lesson-correlation-causation`)
