# Frontier Model Scaling

*   **Module ID:** `module-frontier-model-scaling`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to frontier research in model scaling, including scaling laws relating parameters, data, and compute to model capabilities, reasoning models that allocate additional computation during inference, and mixture-of-experts architectures that decouple parameter count from computational cost.

*   [Scaling Laws and Emergent Behavior](../../lessons/scaling-laws-and-emergent-behavior/) (`lesson-scaling-laws-and-emergent-behavior`)
*   [Reasoning Models and Test-Time Compute](../../lessons/reasoning-models-and-test-time-compute/) (`lesson-reasoning-models-and-test-time-compute`)
*   [Mixture of Experts Architectures](../../lessons/mixture-of-experts-architectures/) (`lesson-mixture-of-experts-architectures`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.
