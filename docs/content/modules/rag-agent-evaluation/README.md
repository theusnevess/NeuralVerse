# RAG & Agent Evaluation

*   **Module ID:** `module-rag-agent-evaluation`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to evaluation methodologies for RAG pipelines and AI agents, including RAG-specific quality metrics inspired by RAGAS, hallucination classification and detection approaches, and agent evaluation dimensions covering planning, tool use, and execution reliability.

## Included Lessons

*   [RAG Evaluation Frameworks](../../lessons/rag-evaluation/) (`lesson-rag-evaluation`)
*   [Hallucination Detection and Analysis](../../lessons/hallucination-evaluation/) (`lesson-hallucination-evaluation`)
*   [Agent Evaluation Methodologies](../../lessons/agent-evaluation/) (`lesson-agent-evaluation`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as multi-modal RAG evaluation, long-context faithfulness assessment, or agentic workflow stress testing.
