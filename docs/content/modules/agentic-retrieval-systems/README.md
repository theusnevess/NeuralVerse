# Agentic Retrieval Systems

*   **Module ID:** `module-agentic-retrieval-systems`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to loop-based agentic retrieval architectures, focusing on Self-RAG and Corrective RAG (CRAG) iteration patterns, knowledge grounding and factual citation attribution, and the taxonomy of retrieval failure modes with their corresponding engineering mitigations.

*   [Agentic Retrieval Systems](../../lessons/agentic-rag/) (`lesson-agentic-rag`)
*   [Knowledge Grounding and Attribution](../../lessons/knowledge-grounding/) (`lesson-knowledge-grounding`)
*   [Retrieval Failure Modes and Mitigation](../../lessons/retrieval-failure-mitigation/) (`lesson-retrieval-failure-mitigation`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

Future lessons may extend this module with topics such as multi-step plan verification, memory-augmented agentic RAG, or graph-based grounding systems.
