# Multimodal Applications

*   **Module ID:** `module-multimodal-applications`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to downstream applications of multimodal architectures, focusing on encoder-decoder autoregressive image captioning, multimodal Transformer question-answering (VQA), and text-to-image/image-to-text cross-modal vector database search.

## Included Lessons

*   [Image Captioning](../../lessons/image-captioning/) (`lesson-image-captioning`)
*   [Visual Question Answering](../../lessons/visual-question-answering/) (`lesson-visual-question-answering`)
*   [Multimodal Retrieval](../../lessons/multimodal-retrieval/) (`lesson-multimodal-retrieval`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as text-to-image diffusion guidance, multi-frame video understanding, or speech-to-text semantic maps.
