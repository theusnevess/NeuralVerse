# Representation Learning in CNNs

*   **Module ID:** `module-representation-learning-cnns`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to spatial representation learning inside deep CNNs, including receptive field growth hierarchies, Gabor-to-semantic feature transitions, and pretrained weight transfers (feature extractors vs. fine-tuning).

## Included Lessons

*   [Receptive Fields](../../lessons/receptive-fields/) (`lesson-receptive-fields`)
*   [Hierarchical Feature Learning](../../lessons/hierarchical-feature-learning/) (`lesson-hierarchical-feature-learning`)
*   [Transfer Learning in Vision](../../lessons/transfer-learning-vision/) (`lesson-transfer-learning-vision`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as neural style transfer, visual saliency maps, class activation mapping (CAM), or adversarial attacks in vision models.
