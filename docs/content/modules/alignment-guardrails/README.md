# Alignment and Guardrails

*   **Module ID:** `module-alignment-guardrails`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to alignment and guardrail approaches for LLMs, including constitutional principles for model behavior, layered guardrail architectures covering input to post-processing, and comprehensive policy enforcement and output validation strategies.

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.
