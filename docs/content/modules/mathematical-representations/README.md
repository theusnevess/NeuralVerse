# Mathematical Representations

*   **Module ID:** `module-mathematical-representations`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to mathematical representations and mappings used in AI, including normalized cosine similarity metrics, geometric linear transformations, and high-dimensional reduction methods (PCA, t-SNE, UMAP).

## Included Lessons

*   [Cosine Similarity](../../lessons/cosine-similarity-math/) (`lesson-cosine-similarity-math`)
*   [Linear Transformations](../../lessons/linear-transformations/) (`lesson-linear-transformations`)
*   [Dimensionality Reduction](../../lessons/dimensionality-reduction/) (`lesson-dimensionality-reduction`)
