# Mathematical Representations — Module Composition

## 1. Purpose

This module organizes lessons related to angular vectors normalization, coordinate grid transformations, and data projections.

It provides an organizational boundary for cosine distances, linear space mapping, PCA, and manifold visualization without duplicating any instructional content.

## 2. Module Learning Aim

Introduce learners to mathematical representations and mappings used in AI, including normalized cosine similarity metrics, geometric linear transformations, and high-dimensional reduction methods (PCA, t-SNE, UMAP).

This module aims to connect vector transformations, spatial stretching, and cluster visualization to engineering use cases, without claiming or certifying competency mastery.

## 3. Included Lessons

### 3.1 Cosine Similarity

*   **Lesson ID:** `lesson-cosine-similarity-math`
*   **Location:** `docs/content/lessons/cosine-similarity-math/lesson-composition.md`
*   **Pedagogical Role:** Explains length normalization, angular similarities, and length invariance in document search.
*   **Relationship to Module Aim:** Fulfills the cosine similarity metric and normalization requirement of the learning aim.

### 3.2 Linear Transformations

*   **Lesson ID:** `lesson-linear-transformations`
*   **Location:** `docs/content/lessons/linear-transformations/lesson-composition.md`
*   **Pedagogical Role:** Details coordinate basis transformations, vector space stretching/shearing, and transformation matrices.
*   **Relationship to Module Aim:** Fulfills the linear space transformation and mapping requirement of the learning aim.

### 3.3 Dimensionality Reduction

*   **Lesson ID:** `lesson-dimensionality-reduction`
*   **Location:** `docs/content/lessons/dimensionality-reduction/lesson-composition.md`
*   **Pedagogical Role:** Explains PCA global variance projection, t-SNE/UMAP neighborhood mappings, and high-dimensional visualization.
*   **Relationship to Module Aim:** Fulfills the dimensionality reduction and embedding visualization requirement of the learning aim.

This module composition does not duplicate any of the instructional content or text from the lesson compositions themselves.

The module structures lessons in the following sequence:
