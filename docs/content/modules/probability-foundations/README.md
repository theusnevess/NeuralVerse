# Probability Foundations

*   **Module ID:** `module-probability-foundations`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to the basic principles of probability that support modern artificial intelligence, including random variables, probability distributions, and belief updating via Bayes' Theorem.

## Included Lessons

*   [Random Variables](../../lessons/random-variables/) (`lesson-random-variables`)
*   [Probability Distributions](../../lessons/probability-distributions/) (`lesson-probability-distributions`)
*   [Bayes' Theorem](../../lessons/bayes-theorem/) (`lesson-bayes-theorem`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as joint and marginal probabilities, continuous distribution functions, Markov chains, or information theory concepts (entropy, KL divergence).
