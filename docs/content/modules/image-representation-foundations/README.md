# Image Representation Foundations

*   **Module ID:** `module-image-representation-foundations`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to computational representations of digital images, including pixel coordinates, intensity grids, channel tensors, color spaces, and resolution downsampling/resizing interpolations.

## Included Lessons

*   [Digital Images and Pixel Representation](../../lessons/pixel-representation/) (`lesson-pixel-representation`)
*   [Image Channels and Color Spaces](../../lessons/color-spaces/) (`lesson-color-spaces`)
*   [Image Resolution, Sampling, and Resizing](../../lessons/resolution-sampling-resizing/) (`lesson-resolution-sampling-resizing`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as gamma correction, image bit depths, image metadata headers, compression algorithms, or spatial transformations.
