# Model Adaptation Fundamentals

*   **Module ID:** `module-model-adaptation`
*   **Status:** `Draft`
*   **Module Type:** `Core Module`

## Module Aim

Introduce learners to the foundations of adapting pre-trained Large Language Models (LLMs), including weight adjustments, learning rate schedules, catastrophic forgetting risks, instruction tuning alignments, and Parameter-Efficient Fine-Tuning (PEFT) low-rank factorization (LoRA) mathematics.

## Included Lessons

*   [Fine-Tuning Fundamentals](../../lessons/fine-tuning-fundamentals/) (`lesson-fine-tuning-fundamentals`)
*   [Instruction Tuning](../../lessons/instruction-tuning/) (`lesson-instruction-tuning`)
*   [Parameter-Efficient Fine-Tuning (PEFT)](../../lessons/peft/) (`lesson-peft`)

## Evidence Boundary Reminder

This Module organizes Lessons. It does not generate Competency Evidence and does not certify mastery. All assessments and competency evidence remain governed by NV-800-M4 and NV-800-M3 respectively.

## Future Expansion Note

Future lessons may extend this module with topics such as prefix tuning, prompt tuning configurations, and quantization-aware adapters (QLoRA).
