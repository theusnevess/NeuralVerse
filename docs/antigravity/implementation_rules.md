# Antigravity Implementation Rules

## Current Phase

UI Foundation.

## Rules

- Do not create educational content.
- Do not implement labs yet.
- Do not implement quizzes yet.
- Do not create backend logic.
- Do not add unnecessary dependencies.
- Keep HTML, CSS, and JavaScript modular.
- Prioritize readability and maintainability.
- Use semantic HTML.
- Keep CSS organized by tokens, base, layout, components, and utilities.
- Avoid visual overengineering.
