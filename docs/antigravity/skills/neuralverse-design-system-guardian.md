# Skill: neuralverse-design-system-guardian

## Responsabilidade
Proteger a consistência visual em todo o projeto.

## Valida
* Tipografia
* Espaçamentos
* Tokens
* Cores
* Bordas
* Sombras

## Bloqueia
* Componentes fora do Design System.
* Hardcoded colors (Cores chumbadas diretamente no código).
* Espaçamentos aleatórios e inconsistentes.
