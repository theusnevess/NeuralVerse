# NV-1700 Completion And Next Experiments

Completion is active only for a completed execution with a terminal result. `CompletionNextExperiments` is the single authority: it consumes the Execution Engine lifecycle, the Laboratory completion summary, the immutable execution snapshot, and Scientific Inspector references. It never reads mutable form values or visible DOM content.

The Completion Deck separates operational completion from the domain scientific outcome. It presents a compact outcome, final measurements from the existing Laboratory completion contract, immutable configuration reference, supported evidence navigation, supported limitations, Research Mode capture state, and repeat action. Reset or a new run clears the active Completion model and continuation deck.

Next Experiments is derived from the current completed model, current Laboratory schema, and registered Lab Ecosystem relationships. Families are repeat, vary one factor, compare, deepen, curriculum continuation, and prerequisite review. Relationship labels and rationales remain sourced from registered metadata; no title similarity, scoring, personalization, or optimal-value claim is used.

The deck uses semantic headings, lists, descriptive links, visible readiness text, logical keyboard order, and a single-column compact layout. Validation covers the ten Laboratories, immutable provenance, reset isolation, recommendation route validity, mobile containment, and the frozen Laboratory regression suites.
