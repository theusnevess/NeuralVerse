# NV-800 — Next-Generation Didactic Architecture

## Status

*   NV-800-M0 — Canonical Didactic Vision — ACTIVE
*   NV-800-M1 — Competency, Mastery, and Engineering Readiness Architecture — ACTIVE

## Purpose

NV-800 defines NeuralVerse as an AI Engineering Knowledge Operating System rather than a conventional course platform.

This architecture governs future work related to:

* curriculum sequencing;
* lesson structure;
* mastery gates;
* competency graphs;
* multi-agent didactic production;
* interactive laboratories;
* engineering readiness scoring;
* source quality;
* curiosity cards;
* portfolio-oriented learning outcomes.

NV-800 is a product and didactic architecture layer. It does not authorize implementation changes by itself.
