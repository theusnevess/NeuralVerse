## Token Implementation Rules

### Registry First Rule
No token may be implemented unless it exists in `docs/design-system/TOKEN_REGISTRY.md`.

### Token Hierarchy
```text
ref (raw scale values)
  ↓
sys (semantic roles — must consume ref tokens)
  ↓
ctx (region/shell assignments — must consume sys tokens)
  ↓
cmp (component tokens — NOT authorized in this task)
```

### Semantic Rule
Semantic tokens must reference reference tokens. No raw values in sys layer.

### Context Rule
Context tokens must reference semantic tokens. No reference token consumption in ctx layer, except where explicitly documented in T4 (ctx.overlay.backdrop consumes ref.color.black per registry).

### Component Tokens
Not authorized in this task unless explicitly present in TOKEN_REGISTRY.md as implementation-ready.

### Allowed Selectors
```text
:root
@media (prefers-reduced-motion: reduce) { :root { ... } }
```

No classes. No element selectors. No IDs. No component selectors.

### Motion Intensity Scale
```text
Approved:   sys.motion.intensity.none
            sys.motion.intensity.reduced
            sys.motion.intensity.low
            sys.motion.intensity.medium
Forbidden:  sys.motion.intensity.high
```
