## Current Phase

UI Foundation

No educational content should be implemented before the interface foundation is completed.

---

## Visual Identity

Primary Inspiration:

* Research Lab Dark
* Computer Vision Simulator

Secondary Inspiration:

* Neural Observatory

---

## Design Principles

1. Content First
2. Clarity Before Decoration
3. Deep Focus
4. Long-Term Readability
5. Scientific Professionalism

---

## User Feeling

The user should feel:

"I am inside a modern AI research laboratory."

Not:

"I am inside a game."

---

## Visual Characteristics

* Dark mode mandatory.
* Minimal visual noise.
* Scientific atmosphere.
* Subtle space-inspired elements.
* Premium appearance.

---

## Forbidden Styles

* Excessive cyberpunk.
* Neon overload.
* Gaming aesthetics.
* Excessive glassmorphism.
* Corporate dashboard appearance.

---

## Navigation Priorities

1. Home (Dashboard)
2. Learning (Curriculum)
3. Modules (Index)
4. Workspace (Reading)
5. Content (Knowledge)
6. Retrieval (Research)
7. Atlas (Graph)
8. Settings

---

## UX Goal

The platform should reduce cognitive load and maximize learning efficiency.
