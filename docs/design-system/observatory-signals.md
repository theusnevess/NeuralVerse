# Observatory Signals

Observatory Signals are the recurring visual motifs that give NeuralVerse its distinctive signature "scientific desk" feel, presenting the system as a premium laboratory instrument.

## Observatory Signals Catalog

| Signal              | Meaning             | Typical Usage                           |
| ------------------- | ------------------- | --------------------------------------- |
| Orbital Arc         | Exploration         | Discovery panels, graph, empty states   |
| Signal Beam         | Active search       | Search, query, discovery                |
| Convergence Point   | Synthesis           | Evidence, compilation, confidence       |
| Constellation Mesh  | Knowledge structure | Graph, relationships, workspace hero    |
| Scientific Grid     | Analytical context  | Inspector, metadata, evidence panels    |
| Directed Trajectory | Progress            | learning sequence, workflow progress    |
| Local Orbit         | Immediate context   | selected reference, active neighborhood |
| Radial Beacon       | Discovery           | suggested paths, new opportunities      |

## Rules of Usage
1. **Subtle & Restrained**: Observatory Signals must be subtle background hints, never dominant foreground graphics.
2. **Never purely decorative**: They must align with the current operational state of the UI (e.g. an active search displays a Signal Beam, whereas showing evidence displays a Convergence Point).
3. **Token Compliance**: Colors must use design tokens (`var(--sys-color-border-subtle)` or `var(--sys-color-accent-primary)` at low opacities).
4. **Motion**: Must respect user reduced motion configurations.
