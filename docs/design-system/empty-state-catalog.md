## Asset Policy

All catalog illustrations come from `website/assets/icons/scientific/`. Do not create custom per-page drawings for empty states. If a future surface needs a new concept, add it to the scientific iconography registry before using it here.

## Copy Policy

Titles are short and action-oriented. Descriptions are limited to two sentences and must not imply failure unless an actual error occurred.
