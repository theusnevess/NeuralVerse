# Interface Copy Guidelines

NeuralVerse copy should help users understand research intent, context, and next action.

## Prefer

- Research Pipeline
- Explore Connections
- Find Relevant Context
- Synthesize Evidence
- Learning Paths
- Content Viewer
- References
- Evidence

## Avoid In User-Facing UI

- Milestone identifiers.
- Runtime or infrastructure language.
- MVP labels.
- Implementation details such as local state, registries, indexes, or compiler internals.
- Repeated route names when navigation already communicates location.

## Pipeline Copy

The Retrieval pipeline should use these user-centered stages:

1. Collect Sources
2. Explore Connections
3. Find Relevant Context
4. Synthesize Evidence

The pipeline description should explain the research flow, not system architecture.
