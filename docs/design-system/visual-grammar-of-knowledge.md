# Visual Grammar of Knowledge

This document defines the canonical mapping from abstract concepts in NeuralVerse to visual motifs and motion profiles. No component may invent a new visual metaphor when an approved concept already exists.

## Canonical Motif Mapping

| Concept         | Primary Motif                   | Associated Motion            | Meaning                                |
| --------------- | ------------------------------- | ---------------------------- | -------------------------------------- |
| Search          | Lens + converging rays          | Convergence                  | Active intentional lookup              |
| Discovery       | Beacon + expanding orbit        | Radial expansion             | Opening a new research path            |
| Evidence        | Multiple lines → synthesis core | Convergence to core          | Source material supporting synthesis   |
| Relationship    | Bridges + connective arcs       | Progressive connection       | Explicit connection between references |
| Memory          | Archive + stacked documents     | Soft stacking                | Research continuity and recall         |
| Session         | Timeline + anchored node        | Gradual restoration          | Persistent investigation state         |
| Knowledge       | Constellation + mesh            | Stabilization                | Organized conceptual space             |
| Compilation     | Signals converging              | Aggregation                  | Multiple inputs becoming synthesis     |
| Confidence      | Stable concentric rings         | Single subtle pulse          | Degree of support or trust             |
| Progress        | Directed trajectory             | Linear advance               | Movement through a sequence            |
| Comparison      | Parallel structures             | Lateral alignment            | Evaluating items side by side          |
| Exploration     | Branching paths                 | Controlled branching         | Moving through alternatives            |
| Validation      | Checkpoint + ring               | Confirmation emphasis        | Accepted or verified state             |
| Warning         | Diverging rays                  | Attention emphasis           | Potential issue or caution             |
| Failure         | Interrupted connection          | Break/disconnect             | Missing, failed, or invalid state      |
| Loading         | Orbit under construction        | Controlled rotation or entry | Work in progress                       |
| Synchronization | Parallel converging waves       | Alignment                    | Separate states becoming consistent    |
| Insight         | Focused burst                   | Single reveal                | Notable discovery or realization       |
| Context         | Framing brackets                | Framing transition           | Local interpretation boundary          |
| History         | Layered timeline                | Sequential reveal            | Previous activity over time            |

## Architecture Principles
1. **Conceptual Consistency**: Visual systems must strictly adhere to the mapping above.
2. **Minimal decoration**: Every stroke must represent a semantic value.
3. **No Neon/Cyberpunk styling**: Use scientific, instrument-like presentations governed exclusively by tokens.
