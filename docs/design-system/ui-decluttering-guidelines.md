# UI Decluttering Guidelines

Every visible element in NeuralVerse must justify its presence.

## Keep Visible When It Helps

- User orientation.
- Task completion.
- Research continuity.
- Decision-making.
- Accessibility and feedback.

## Remove Or Collapse When It Is

- Duplicate route information.
- Decorative metadata.
- Internal project terminology.
- Debug or runtime status.
- Repeated badges or chips that do not clarify state.

## Page Header Rule

Home may have an intentional hero. Other pages should begin with useful content quickly. If a route label is only present for semantic structure, use a visually hidden heading and keep the visible layout clean.

## Context Panel Rule

The context panel should show compact, useful context only. If there is no useful context, prefer a compact empty state or collapse behavior over filler sections.
