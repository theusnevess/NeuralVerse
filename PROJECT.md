# NeuralVerse — Project Context

## Purpose

NeuralVerse is a personal AI learning and research platform focused on artificial intelligence, machine learning, computer vision, generative AI, agents, retrieval, and research workflows.

## Current Role of the Project

Treat NeuralVerse as a serious product and portfolio-grade platform, not a prototype.

## Current Stack

- HTML
- CSS
- JavaScript
- React/Vite island where applicable
- Static/frontend-first architecture

## Architecture Rules

- Preserve current architecture.
- Do not introduce backend, auth, database, external APIs, or heavy dependencies unless explicitly requested.
- Keep UI logic modular and testable.
- Prefer small, safe changes.
- Preserve existing design language.
- Maintain accessibility and responsive behavior.

## Visual Direction

Premium dark AI research platform with:

- scientific interface
- subtle cyan/blue accents
- precise spacing
- low visual noise
- knowledge-system/research-observatory feeling
- no generic AI clichés
- no mascots
- no excessive gradients

## Validation

For UI work, validate:

- desktop layout
- tablet layout
- mobile layout
- console errors
- route behavior
- keyboard/focus states when relevant

## Important Project Areas

- Graph visualization
- Retrieval workspace
- Learning/curriculum architecture
- Visual system
- App shell and navigation
