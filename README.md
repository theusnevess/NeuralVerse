# NeuralVerse

NeuralVerse is a personal AI engineering learning platform.

Current phase: UI Foundation.

The current goal is to establish the project structure, documentation base, and frontend foundation before creating educational content.

## Scope

Allowed now:

- Project structure
- UI foundation
- Design system planning
- Layout planning
- Component planning

Not allowed yet:

- Lessons
- Quizzes
- Labs
- Podcasts
- Papers
- Backend
- Real educational modules
