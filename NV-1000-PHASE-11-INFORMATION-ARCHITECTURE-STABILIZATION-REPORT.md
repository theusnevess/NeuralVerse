# NV-1000 Phase 11 Information Architecture Stabilization

## Executive Summary

The Laboratory Workspace now follows a single in-flow hierarchy: Scientific Header, Canvas Region, Instrument Bar, then Drawer Layer. Essential telemetry is limited to the first six existing inspector cards. Inspector details, parameters, research surfaces, log, and continuations no longer occupy the canvas as permanent overlays.

## Baseline Findings

The two mobile failures were caused by the telemetry HUD intercepting Step. The remaining failure expected a removed, duplicate Inspector metrics bar.

## Root Causes

- Phase 9 and 10 rules retained absolute HUD placement, a fixed Scientific Log, and an overlay parameter panel.
- The canvas root inherited `display: contents`, hiding its geometry and allowing later regions to compete for the same viewport area.
- Secondary observation panels were simultaneously visible, consuming canvas height without improving the primary experiment surface.
- Legacy tests treated duplicated metrics as a visual requirement.

## Architecture

Before:

```text
Header
Canvas + overlay Inspector + overlay XAI + floating observations
Floating parameter/control treatment + fixed log
Research/continuations
```

After:

```text
Scientific Header
Canvas Region
  Essential HUD | Primary visualization | Scientific Findings HUD
Instrument Bar
Drawer Layer
  Inspector Details | Parameters | Research | Scientific Log | Continuations
```

## Inspector Reduction and Drawers

- Essential telemetry is derived from the existing first inspector section and capped at six cards.
- Other inspector cards remain available through the existing single-expand accordion and drawer controls.
- Parameters remain in normal flow and collapse after execution begins.
- Scientific Log is an in-flow, bounded disclosure; only its entries may scroll.
- Research persistence and controls remain unchanged, but render in the drawer layer.

## DOM and CSS Changes

- `laboratory-controller.js` renders execution step/status in the Instrument Bar and places the final Inspector DOM in the drawer layer.
- `laboratories.css` establishes the authoritative Phase 11 grid and neutralizes Phase 9/10 positioning for the workspace regions.
- HUD telemetry is non-interactive, preventing it from intercepting controls.
- Secondary observation panels are removed from the permanent canvas surface.

## Tests Updated

- Replaced the obsolete duplicated Inspector metrics contract with essential-HUD coverage.
- Updated Scientific Log contract from fixed overlay to in-flow drawer.
- Added Phase 11 DOM hierarchy, desktop overlap, responsive scroll, and pointer-interception checks.
- Updated observation coverage to assert the visible primary experiment surface rather than unrelated secondary labels.

## Responsive, Accessibility, and Scroll Audit

- Desktop: canvas, telemetry, findings, instrument bar, and drawers have distinct non-overlapping regions.
- Tablet/mobile: canvas, essential telemetry, findings, instrument bar, then drawers stack in document order.
- Responsive audit passed at 1440x900, 1280x800, 768x1024, 390x844, and 360x740.
- Keyboard and ARIA tests passed. Existing disclosure controls retain `aria-expanded` and `aria-controls`.
- The Phase 11 audit rejects horizontal overflow and independently scrollable canvas/HUD/instrument regions. A region only counts as independently scrollable when its computed overflow enables scrolling.
